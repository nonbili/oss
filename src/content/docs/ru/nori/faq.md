## Как сохранять ссылки в Nori из мобильного браузера?

Используйте стандартное системное меню «Поделиться»:

1. В браузере (Chrome, Firefox, Safari, Brave и др.) нажмите **Поделиться**.
2. Выберите **Nori** из списка приложений.
3. Укажите целевой список для сохранения ссылки или включите опцию **Быстрое сохранение ссылок** в настройках, чтобы сохранять ссылки в назначенный список без лишних запросов.

## Можно ли открывать закладки прямо в приложении браузера, а не во встроенной вкладке?

Да. Перейдите в **Настройки → Общие** и включите параметр **Открывать ссылки в браузере по умолчанию**. При включении этого параметра нажатие на любую закладку немедленно передаст адрес во внешний браузер вашего устройства.

## Как импортировать закладки из браузеров на компьютере?

Экспортируйте закладки в файл HTML:

- **Chrome / Brave / Edge**: Откройте диспетчер закладок (`Ctrl+Shift+O` или `Cmd+Option+B`) → нажмите меню с тремя точками `⋮` → выберите **Экспортировать закладки**.
- **Firefox**: Откройте библиотеку (`Ctrl+Shift+O` или `Cmd+Shift+O`) → **Импорт и резервные копии** → **Экспорт закладок в HTML-файл…**.
- **Safari**: Файл → **Экспортировать закладки…**.

Затем в Nori откройте **Настройки → Закладки → Импорт закладок**, выберите полученный `.html`-файл, и Nori перенесёт все ссылки и папки в соответствующие списки.

## Можно ли создавать резервные копии и восстанавливать закладки?

Да. В меню **Настройки → Закладки**:

- **Экспорт резервной копии**: Сохраняет полный JSON-файл со всеми списками, закладками, тегами и настройками.
- **Восстановить копию**: Восстанавливает данные из существующего файла бэкапа Nori.
- **Экспорт в HTML / текст**: Создаёт файл закладок HTML для браузеров или читаемый текстовый список.

## Как работает синхронизация между устройствами?

Nori Sync связывает ваши мобильные приложения, десктопные клиенты и браузерные расширения:

- Закладки кэшируются локально на каждом устройстве для полноценной работы без подключения к сети.
- При подключении к интернету изменения автоматически синхронизируются между всеми активными устройствами.

## Отслеживает ли браузерное расширение историю просмотров?

Нет. Nori не отслеживает историю просмотров и не читает содержимое веб-страниц. Расширение получает адреса сайтов только тогда, когда вы открываете всплывающее окно и нажимаете кнопку добавления текущей вкладки.
