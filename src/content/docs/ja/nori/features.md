## リストによる整理

- **複数リスト**: SNS、仕事、読書、ニュース、AI ツールなど、目的別のカテゴリにリンクを分類できます。
- **リストの管理**: ワークフローに合わせて、リストの作成、名前の変更、非表示、削除が行えます。
- **ドラッグして並べ替え**: リストやブックマークをお好みの順序にドラッグ＆ドロップで並べ替えられます。
- **一括移動と削除**: 複数のブックマークを選択して別リストへ移動したり、不要になった項目を一括削除したりできます。

## 起動とブラウジング

- **デフォルトブラウザへの引き渡し**: お使いのシステム標準ブラウザアプリでブックマークを直接開きます。
- **アプリ内 Custom Tabs**: Android や iOS では、アプリを切り替えずに手早く閲覧できる組み込みの Custom Tabs / Safari View Controller シートを選択可能です。
- **ファビコンの自動取得**: ドメインのファビコンを自動的に取得して表示します。シンプルな Nori アイコンに切り替えることも可能です。

## 共有メニュー連携

- **システム共有の受信**: Web ブラウザ、チャットアプリ、リーダーなど、あらゆるアプリの共有メニューから Nori に直接リンクを送信できます。
- **保存先リストの選択**: 共有時に保存先のリストをその場で選択できます。
- **クイック保存モード**: 指定したリストを設定しておくことで、確認ダイアログなしで即座に自動保存できます。
- **ページタイトルの自動取得**: リンク追加時に Web ページのタイトルを自動取得します。

## 表示モード

- **コンパクトランチャー**: 1 タップでの素早い起動と情報密度の高さを重視したボタン表示。
- **プレビューカード**: Web サイトのカバー画像と説明文を表示するビジュアル重視のカード形式。
- **レイアウト密度**: 画面サイズや好みに合わせて、1 列表示と 2 列グリッド表示を切り替えられます。

## 検索ドロワーと履歴

- **クイック検索**: タイトル、URL、カスタムタグからすべてのブックマークをリアルタイムに検索・絞り込みできます。
- **並べ替えオプション**: 新しい順、古い順、名前順（A–Z）、逆順（Z–A）でブックマークを並べ替えられます。
- **最近開いたリンク**: リスト内を探すことなく、最近起動したリンクをすぐに再度開けます。
- **最近追加したリンク**: 新しく保存したブックマークを一覧ですぐに確認できます。

## インポート、エクスポート、バックアップ

- **ブラウザ HTML インポート**: Chrome、Firefox、Safari、Edge、Brave などからエクスポートした標準 HTML ブックマークファイルをインポートできます。
- **プレーンテキスト形式のエクスポート**: メモやドキュメント用に、タイトルと URL の読みやすいテキスト一覧を出力できます。
- **完全なバックアップと復元**: すべての設定、リスト、ブックマークを含む完全な JSON バックアップファイルを保存・復元できます。

## クラウド同期

- **マルチデバイス同期**: Nori Sync（オプション）を利用して、スマートフォン、タブレット、デスクトップ、ブラウザ拡張機能の間でリストとブックマークを自動同期できます。
- **ローカルファースト設計**: すべてのブックマークは端末内にローカルキャッシュされるため、インターネット接続がない環境でも完全にオフラインで利用できます。
