*2026年10月22日公開*

**Nora 0.9.0** では、Android、iOS、デスクトップ向けに内蔵フィードリーダーが追加されました。X、Instagram、Bluesky、Mastodon などの対応ネットワークのアカウントをフォローし、自分だけの時系列タイムラインに整理できます。多くのソースはサインイン不要で利用可能です。

すべての投稿をまとめて閲覧することも、関心ごとにタイムラインを分けることも、写真や動画のグリッド表示に切り替えることもできます。

## 各種ソーシャルネットワークのアカウントをフォロー

Nora のタブで対応しているプロフィールやコミュニティを開き、メニューから **ウォッチ** を選択します。最新の投稿が Nora の **フィード** に表示されます。返信を読んだりリアクションしたいときは、投稿をタップして元のページを開けます。

以下のアカウントをフォローできます：

- **X (Twitter)**、**Instagram**、**Threads**、**Bluesky**、**TikTok** のプロフィール
- 各サーバーの **Mastodon** プロフィール
- **Reddit** のサブレディットおよびユーザープロフィール
- **Facebook** のページ、プロフィール、グループ

複数のソースを一度に追加するには、プロフィールリンクの一覧を貼り付けるか、OPML ファイルをインポートします。OPML のフォルダはそのままタイムラインになるため、これまでの整理状態をそのまま引き継げます。**ソースの管理** 画面では、フォロー中のアカウントの検索、フィルタ、並べ替え、再エクスポートが可能です。

## 自分好みにタイムラインを整理

友達、ニュース、趣味などを別々の **カスタムタイムライン** に分けられ、それぞれに好みの絵文字アイコンとフィードタブを設定できます。タイムラインを新しいタブのページにピン留めして素早くアクセスすることも、すべてのソースをひとつのフィードにまとめることも可能です。

タイムライン内では、投稿者のアバターや名前をタップしてその人の投稿に絞り込むことができます。また、フィード上部のピッカーからソースを選択することもできます。

Nora が更新を確認する頻度や、どの投稿で通知を受け取るかも設定可能です。全ソース共通のデフォルト設定のほか、タイムラインごとに調整したり、個々のソースをミュートすることもできます。ログインが必要なネットワークでは、使用する Nora プロフィールを指定したり、サインイン状態のチェックを無効にしたりできます。

ウォッチ中のソースやタイムラインは設定のバックアップや任意のクラウド同期に含まれるため、複数の端末間で引き継ぐことができます。

## 写真と動画の閲覧

タイムラインを **写真と動画のみ** に切り替えると、メディアをグリッド表示で閲覧できます。画像や動画を開いてギャラリーをスワイプしたり、写真を拡大したり、動画を再生したり、端末にメディアをダウンロードしたりできます。

Nora はフィードの投稿とメディアをローカルにキャッシュします。メディアストレージの上限設定、キャッシュのクリア、メディアの先読みを Wi-Fi 接続時のみに制限する設定が可能です。

## その他の改善点

本リリースでは以下の機能も追加されています：

- **タブの並べ替え:** モバイルのタブ切り替え画面で、長押ししてドラッグして並べ替え。
- **ページ内検索:** 一致件数のリアルタイム表示と「次へ/前へ」ボタンで、開いている Web ページ内を検索。
- **プロフィール対応リンク:** リンクは元のタブのプロフィール内で開き、タブを長押しして別のプロフィールで再度開くことが可能。
- **同期機能の改善:** 設定、ブックマーク、ユーザースタイルの変更が端末間でマージされ、ローカルバックアップからの復元にも対応。
