## モバイルブラウザから Nori にリンクを保存するには？

システムの標準共有メニューを利用します:

1. ブラウザ（Chrome、Firefox、Safari、Brave など）で **共有** をタップします。
2. アプリ一覧から **Nori** を選択します。
3. 保存先のリストを選択します。または、設定で「共有リンクをクイック保存」を有効にしておくと、確認なしで指定のリストに直接保存されます。

## アプリ内タブではなくブラウザアプリで直接開くことはできますか？

はい。**設定 → 一般** で **デフォルトブラウザでリンクを開く** をオンにしてください。有効にすると、ブックマークをタップした際にシステムの既定ブラウザアプリへ即座に引き渡されます。

## デスクトップブラウザからブックマークをインポートするには？

既存のブックマークを HTML ファイルとしてエクスポートします:

- **Chrome / Brave / Edge**: ブックマークマネージャー（`Ctrl+Shift+O` または `Cmd+Option+B`）を開く → `⋮` メニューをクリック → **ブックマークをエクスポート** を選択。
- **Firefox**: ライブラリ（`Ctrl+Shift+O` または `Cmd+Shift+O`）を開く → **インポートとバックアップ** → **HTML からブックマークをエクスポート…**。
- **Safari**: ファイル → **ブックマークを書き出す…**。

その後、Nori で **設定 → ブックマーク → ブックマークをインポート** を開き、書き出した `.html` ファイルを選択すると、リンクとフォルダが対応するリストにインポートされます。

## ブックマークのバックアップと復元はできますか？

はい。**設定 → ブックマーク** から実行できます:

- **バックアップをエクスポート**: すべてのリスト、ブックマーク、タグ、設定を含む完全な JSON バックアップファイルを保存します。
- **バックアップを復元**: 以前保存した Nori バックアップファイルから復元します。
- **HTML / プレーンテキスト形式でエクスポート**: 他のブラウザと互換性のある HTML ファイルや、読みやすいテキスト一覧を作成できます。

## 複数端末での同期はどのように動作しますか？

Nori Sync により、モバイルアプリ、デスクトップアプリ、ブラウザ拡張機能を接続できます:

- 各端末にブックマークがローカルキャッシュされるため、完全なオフライン状態でも動作します。
- インターネット接続時は、すべてのアクティブなクライアント間で変更がスムーズに同期されます。

## ブラウザ拡張機能は閲覧履歴を追跡しますか？

いいえ。Nori はブラウザの閲覧履歴を監視したり、Web ページのコンテンツを読み取ったりしません。拡張機能のポップアップを開いて現在のタブをブックマーク保存した時のみ URL を受信します。
