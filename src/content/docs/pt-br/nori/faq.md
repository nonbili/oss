## Como salvo links no Nori a partir do navegador do meu celular?

Use o menu padrão de compartilhamento do sistema:

1. No seu navegador (Chrome, Firefox, Safari, Brave, etc.), toque em **Compartilhar**.
2. Selecione o **Nori** na lista de aplicativos.
3. Escolha a lista de destino onde deseja guardar o link ou ative **Salvar links compartilhados rapidamente** nas configurações para salvar diretamente em uma lista definida sem confirmação.

## Posso abrir os favoritos diretamente no aplicativo do meu navegador em vez de uma aba interna?

Sim. Acesse **Configurações → Geral** e ative **Abrir links no navegador padrão**. Quando ativado, tocar em qualquer favorito enviará a URL imediatamente para o navegador padrão do seu telefone.

## Como importo meus favoritos dos navegadores de computador?

Exporte seus favoritos atuais para um arquivo HTML:

- **Chrome / Brave / Edge**: Abra o Gerenciador de favoritos (`Ctrl+Shift+O` ou `Cmd+Option+B`) → clique no menu `⋮` → selecione **Exportar favoritos**.
- **Firefox**: Abra a Biblioteca (`Ctrl+Shift+O` ou `Cmd+Shift+O`) → **Importar e backup** → **Exportar favoritos para HTML…**.
- **Safari**: Arquivo → **Exportar favoritos…**.

Em seguida, no Nori, vá em **Configurações → Favoritos → Importar favoritos**, selecione o arquivo `.html` e o Nori importará todos os links e pastas para as listas correspondentes.

## Posso fazer backup e restaurar meus favoritos?

Sim. Em **Configurações → Favoritos**:

- **Exportar backup**: Salva um arquivo de backup JSON completo com todas as listas, favoritos, tags e configurações.
- **Restaurar**: Restaura seus dados a partir de um arquivo de backup anterior do Nori.
- **Exportar HTML / Exportar texto simples**: Gera um arquivo HTML compatível com navegadores ou uma lista de texto legível.

## Como funciona a sincronização entre dispositivos?

O Nori Sync conecta seus apps móveis, programas de desktop e extensões de navegador:

- Os favoritos continuam salvos localmente em cada dispositivo para funcionamento offline completo.
- Ao se conectar, as alterações são sincronizadas perfeitamente entre todos os dispositivos ativos.

## A extensão de navegador monitora minha atividade de navegação?

Não. O Nori não monitora seu histórico de navegação nem lê o conteúdo das páginas acessadas. A extensão só recebe URLs quando você abre a janela popup e clica para salvar a aba atual como favorito.
