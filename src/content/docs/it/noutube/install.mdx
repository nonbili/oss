## Dopo l'Installazione

- **Mobile**: Apri un link di YouTube o YouTube Music in NouTube se il tuo dispositivo ti chiede quale app utilizzare. Su iOS, partecipa alla beta tramite TestFlight.
- **Desktop**: Conferma che la riproduzione funzioni nel modo previsto prima di modificare le impostazioni avanzate.
- **Estensione**: Fissa l'estensione NouTube sulla barra degli strumenti del browser, oppure consulta [Estensione per browser](/it/noutube/extension/) per i dettagli.
- Continua con [Panoramica](/it/noutube/) per il contesto del prodotto, o [Funzionalità](/it/noutube/features/) per l'elenco completo delle capacità.
