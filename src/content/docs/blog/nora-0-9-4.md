*Published on November 3, 2026*

A copied post link should be easy to share, and a video download should get past **Parsing**. **Nora 0.9.4 for mobile** addresses both, with a small set of fixes for sharing links, saving files, and watching TikTok videos.

## Share X Links Without the Extra Tokens

Nora now removes X share parameters such as `s` and `t` when you copy or share a post link. For example:

```text
Before: https://x.com/nonbili/status/1234567890?s=20&t=example
After:  https://x.com/nonbili/status/1234567890
```

The post address stays intact; the extra share tokens are removed. This cleanup applies to X and Twitter post URLs, so parameters with the same short names on unrelated pages are left alone.

## Get Past “Parsing” When Saving Videos

Some video downloads could get stuck at the **Parsing** stage before the download began. This release fixes that failure so affected downloads can proceed.

Files generated by a web page through a `blob:` URL also keep their intended filenames when available. That makes saved files easier to recognize later.

## Restore TikTok Fullscreen Controls

Nora's TikTok fullscreen controls could fail to appear when the page script ran before the page body was ready. The controls now handle that loading order, so the fullscreen button can appear as expected.

See the [release notes on GitHub](https://github.com/nonbili/Nora/releases/tag/v0.9.4) for the complete list of changes.
