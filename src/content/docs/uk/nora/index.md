Nora — це браузер для Android, iOS та комп'ютерів, оптимізований для сервісів соціальних мереж.

Він зберігає оригінальні вебсайти сервісів, додаючи зручні вбудовані можливості, як-от окреме сховище для облікових записів, списки блокування, інструменти завантаження, очищення URL-адрес і налаштування CSS.

## Основне

- Без реклами
- Кілька облікових записів з окремим сховищем файлів cookie
- Підтримка списків блокування EasyList та EasyPrivacy
- Завантаження медіа
- Виділення тексту та масштабування
- Видалення параметрів відстеження з URL-адрес
- Підтримка власного CSS

## Перший запуск

Розумне початкове налаштування:

1. Відкрийте сервіс, яким користуєтеся найчастіше.
2. Увійдіть і переконайтеся, що вебверсія нормально працює всередині Nora.
3. Створіть додаткові профілі, якщо потрібне суворе розділення між обліковими записами.
4. Увімкніть списки блокування та перевірте завантаження медіа на потрібних вам сервісах.
5. Додавайте власний CSS лише після того, як базовий перегляд працюватиме стабільно.

## Як це працює

Nora є оболонкою для вебсайтів сервісів, а не переписуванням кожної мережі у вигляді окремого нативного клієнта.

Такий підхід зберігає звичний вигляд сайтів і водночас дозволяє Nora додавати:

- Блокування реклами
- Ізоляцію файлів cookie між обліковими записами
- Інструменти завантаження медіа
- Покращення для конкретних сервісів
