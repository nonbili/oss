O Nora é disponibilizado como uma aplicação para computador no Linux, macOS e Windows.

## O que a versão para computador adiciona

A versão para computador adiciona uma disposição concebida para ecrãs maiores, incluindo uma vista em painel (deck) para navegar por várias linhas cronológicas com maior conforto.

Isso torna a versão para computador a melhor opção quando:

- Monitoriza vários feeds ao mesmo tempo
- Mantém espaços de trabalho separados abertos para diferentes contas ou serviços
- Pretende que o Nora funcione como um navegador diário persistente em vez de uma ferramenta móvel rápida

## O que esperar

A versão para computador mantém o mesmo modelo geral de produto que a versão móvel:

- Abrir sites sociais suportados dentro de uma única aplicação
- Utilizar separação de contas e ferramentas de navegação num ecrã maior
- Instalar pacotes nativos para Linux, macOS ou Windows
