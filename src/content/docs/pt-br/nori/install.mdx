## Após a instalação

- **Mobile**: Experimente compartilhar um link do seu navegador para o Nori através do menu de compartilhamento para verificar o funcionamento.
- **Desktop**: No Linux (AppImage), garanta que GTK 3 e `webkit2gtk-4.1` estejam instalados (`libwebkit2gtk-4.1-0` no Debian/Ubuntu, `webkit2gtk4.1` no Fedora, `webkit2gtk-4.1` no Arch).
- **Extensão**: Fixe a extensão do Nori na barra de ferramentas do seu navegador para salvar e buscar favoritos com apenas um clique.
- Prossiga com a [Visão geral](/pt-br/nori/) para o contexto do produto ou com os [Recursos](/pt-br/nori/features/) para ver a lista completa de funcionalidades.
