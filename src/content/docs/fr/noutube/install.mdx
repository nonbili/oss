## Après l'installation

- **Mobile** : Ouvrez un lien YouTube ou YouTube Music dans NouTube si votre appareil vous demande quelle application utiliser. Sur iOS, rejoignez la bêta via TestFlight.
- **Bureau** : Vérifiez que la lecture fonctionne comme prévu avant de modifier les paramètres avancés.
- **Extension** : Épinglez l'extension NouTube à la barre d'outils de votre navigateur, ou consultez [Extension de navigateur](/fr/noutube/extension/) pour plus de détails.
- Poursuivez avec la [Présentation](/fr/noutube/) pour le contexte du produit, ou les [Fonctionnalités](/fr/noutube/features/) pour la liste complète des capacités.
