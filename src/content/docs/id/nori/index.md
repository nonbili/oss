Nori adalah pengelola dan peluncur markah open-source yang dirancang untuk akses harian yang cepat di perangkat seluler, komputer desktop, dan browser web.

Alih-alih menimbun tautan di dalam struktur folder browser yang dalam atau ekosistem tertutup, Nori mengatur markah Anda ke dalam daftar yang rapi dan terarah dengan peluncuran instan, pencarian, kartu pratinjau visual, dan integrasi menu berbagi sistem.

## Fitur Utama

- Beberapa daftar markah kustom
- Peluncuran instan ke browser default sistem atau Custom Tabs bawaan
- Simpan tautan yang dibagikan dari aplikasi apa pun dengan pemilih daftar dan opsi simpan cepat
- Mode peluncur ringkas dan mode kartu pratinjau dengan gambar sampul situs web
- Panel pencarian cepat dengan pemfilteran kata kunci dan tag
- Riwayat peluncuran yang baru saja digunakan dan baru saja ditambahkan
- Impor dan ekspor melalui markah HTML standar, teks biasa, dan cadangan JSON lengkap
- Tampilan fleksibel: Terang, Gelap, AMOLED, dan warna aksen kustom
- Ekstensi browser lokal-utama untuk Chrome dan Firefox
- Aplikasi desktop lintas platform untuk Linux, macOS, dan Windows
- Sinkronisasi cloud multiperangkat opsional melalui Nori Sync

## Platform

- **Android**: Tersedia di Google Play dan rilis APK langsung di GitHub.
- **iOS**: Tersedia di App Store untuk iPhone dan iPad.
- **Desktop**: Aplikasi native mandiri untuk Linux (AppImage & tarball), macOS (Apple Silicon & Intel), dan Windows.
- **Ekstensi Browser**: Ekstensi Manifest V3 untuk Mozilla Firefox dan Google Chrome.

## Penggunaan Pertama

Langkah konfigurasi awal yang disarankan:

1. Buat beberapa daftar untuk kategori tautan umum Anda (misalnya `Harian`, `Alat`, `Bacaan`, `Kerja`).
2. Tambahkan tautan utama Anda atau impor markah yang ada dari ekspor HTML browser Anda.
3. Coba buka markah untuk memastikan browser default Anda membuka tautan seperti yang diharapkan.
4. Coba bagikan halaman web dari browser seluler Anda ke Nori menggunakan menu berbagi sistem.
5. Sesuaikan pengaturan tampilan, seperti mode gelap atau warna aksen pilihan Anda.

## Cara Kerja

Nori memisahkan koleksi markah Anda dari mesin browser tertentu:

- Di Android, markah dibuka melalui Custom Tabs menggunakan `expo-web-browser` atau langsung dialihkan ke aplikasi browser default Anda.
- Di iOS, markah dibuka melalui sheet browser native atau browser default sistem.
- Di desktop dan ekstensi, markah langsung dibuka di tab browser aktif Anda.

Pendekatan ini memastikan Anda selalu menjelajah dengan pemblokir iklan, status masuk, dan profil browser pilihan Anda tetap utuh, sembari menjaga semua tautan tetap teratur dalam satu peluncur yang cepat dan mudah dicari.
