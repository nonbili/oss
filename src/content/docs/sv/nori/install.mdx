## Efter installation

- **Mobil**: Prova att dela en länk från din webbläsare till Nori via systemets delningsmeny för att verifiera länkhanteringen.
- **Desktop**: För Linux AppImage, se till att GTK 3 och `webkit2gtk-4.1` är installerade (`libwebkit2gtk-4.1-0` på Debian/Ubuntu, `webkit2gtk4.1` på Fedora, `webkit2gtk-4.1` på Arch).
- **Tillägg**: Fäst Nori-tillägget i webbläsarens verktygsfält för snabb bokmärkning och sökning med ett klick.
- Fortsätt med [Översikt](/sv/nori/) för produktkontext, eller [Funktioner](/sv/nori/features/) för den fullständiga listan över funktioner.
