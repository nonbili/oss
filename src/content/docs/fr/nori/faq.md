## Comment enregistrer des liens dans Nori depuis mon navigateur mobile ?

Utilisez le menu de partage standard du système :

1. Dans votre navigateur (Chrome, Firefox, Safari, Brave, etc.), appuyez sur **Partager**.
2. Sélectionnez **Nori** dans la liste des applications.
3. Choisissez la liste de destination où vous souhaitez enregistrer le lien, ou activez **Enregistrement rapide des liens partagés** dans les paramètres pour enregistrer directement dans une liste prédéfinie sans invite.

## Puis-je ouvrir les favoris directement dans mon navigateur plutôt que dans un onglet intégré ?

Oui. Rendez-vous dans **Paramètres → Général** et activez **Ouvrir les liens dans le navigateur par défaut**. Lorsque cette option est activée, appuyer sur un favori transmet immédiatement l'URL à l'application de navigateur par défaut de votre téléphone.

## Comment importer mes favoris depuis des navigateurs pour ordinateur ?

Exportez vos favoris actuels dans un fichier HTML :

- **Chrome / Brave / Edge** : Ouvrez le Gestionnaire de favoris (`Ctrl+Maj+O` ou `Cmd+Option+B`) → cliquez sur le menu `⋮` → sélectionnez **Exporter les favoris**.
- **Firefox** : Ouvrez la Bibliothèque (`Ctrl+Maj+O` ou `Cmd+Maj+O`) → **Importation et sauvegarde** → **Exporter les marque-pages au format HTML…**.
- **Safari** : Fichier → **Exporter les signets…**.

Ensuite, dans Nori, allez dans **Paramètres → Favoris → Importer des favoris**, sélectionnez le fichier `.html`, et Nori importera tous les liens et dossiers dans les listes correspondantes.

## Puis-je sauvegarder et restaurer mes favoris ?

Oui. Dans **Paramètres → Favoris** :

- **Exporter une sauvegarde** : Enregistre un fichier de sauvegarde JSON complet contenant l'ensemble de vos listes, favoris, étiquettes et paramètres.
- **Restaurer** : Restaure vos données à partir d'un fichier de sauvegarde Nori existant.
- **Exporter en HTML / Exporter en texte brut** : Crée un fichier HTML compatible avec les navigateurs ou une liste de texte lisible.

## Comment fonctionne la synchronisation multi-appareils ?

Nori Sync connecte vos applications mobiles, vos applications de bureau et vos extensions de navigateur :

- Les favoris restent enregistrés localement sur chaque appareil pour une utilisation autonome hors ligne.
- Une fois connecté, les modifications sont synchronisées de manière transparente sur tous les appareils actifs.

## L'extension de navigateur suit-elle mon activité de navigation ?

Non. Nori ne surveille pas votre historique de navigation et ne lit pas le contenu des pages web. L'extension ne reçoit des URL que lorsque vous ouvrez la fenêtre contextuelle et cliquez pour enregistrer l'onglet en cours.
