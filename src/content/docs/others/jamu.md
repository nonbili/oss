Jamu is a focused mobile companion designed to help learners study, read, and practice the Japanese language.

- **Source Code**: [nonbili/Jamu](https://github.com/nonbili/Jamu)

## Key Features

- **Gojuon (五十音)**: Interactive Hiragana and Katakana charts with stroke orders and audio pronunciation.
- **Numbers (数字)**: Number reading practice and counter drills.
- **NHK Easy News**: Read simplified Japanese news articles with interactive furigana annotations and vocabulary lookups.
- **Practice Quizzes**: Test character recognition and vocabulary comprehension with quick quiz sessions.
- **Cultural Trivia (豆知識)**: Learn practical language tips, nuances, and everyday cultural insights.

## Development

Built with React Native and Expo:

```bash
git clone https://github.com/nonbili/Jamu.git
cd Jamu
bun install
bun run start
```
