## 설치 후

- **모바일**: 웹 브라우저에서 시스템 공유 메뉴를 사용해 Nori로 링크를 공유해 보며 링크 처리를 확인하세요.
- **데스크톱**: Linux AppImage의 경우 GTK 3 및 `webkit2gtk-4.1`이 설치되어 있는지 확인하세요(Debian/Ubuntu는 `libwebkit2gtk-4.1-0`, Fedora는 `webkit2gtk4.1`, Arch는 `webkit2gtk-4.1`).
- **확장 프로그램**: 빠른 원클릭 북마크 및 검색을 위해 Nori 확장 프로그램을 브라우저 툴바에 고정하세요.
- 제품 맥락은 [개요](/ko/nori/)에서, 전체 기능 목록은 [기능](/ko/nori/features/)에서 계속 확인하세요.
