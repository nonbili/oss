Nori містить локально орієнтоване розширення браузера для Mozilla Firefox та Google Chrome.

## Основні можливості

- **Дзеркальний мобільний досвід**: спливне вікно розширення надає ті самі списки, панель пошуку, історію, керування списками та налаштування, що й мобільна програма.
- **Додавання закладок в один клік**: миттєво зберігайте поточну вкладку у вибраний список з автоматичним отриманням заголовка.
- **Швидка панель запуску**: шукайте та відкривайте збережені посилання в нових вкладках безпосередньо з панелі інструментів браузера.
- **Локальне сховище**: зберігає закладки локально у сховищі розширення браузера з необов'язковою підтримкою Nori Sync.
- **Орієнтація на приватність**: історія переглядів і вміст сторінок не відстежуються. Nori отримує лише ті посилання, які ви явно зберігаєте.

## Встановлення розширення

Встановіть Nori безпосередньо з офіційних магазинів розширень:

- [Firefox Add-ons](https://addons.mozilla.org/addon/nori/)
- [Chrome Web Store](https://chromewebstore.google.com/detail/nori/ojgmnocnegcbhlmfoackgoocnjbfejpg)

## Збирання з вихідного коду

Розширення має відкритий вихідний код і створене за допомогою [WXT](https://wxt.dev/) з використанням Manifest V3:

```bash
cd extension
bun install
bun run dev          # Режим розробки для Chrome
bun run dev:firefox  # Режим розробки для Firefox
bun run build:all    # Зібрати готові zip-пакунки
```
