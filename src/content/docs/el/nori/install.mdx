## Μετά την Εγκατάσταση

- **Κινητό**: Δοκιμάστε να κοινοποιήσετε έναν σύνδεσμο από το πρόγραμμα περιήγησης στο Nori χρησιμοποιώντας το μενού κοινοποίησης του συστήματος για να επαληθεύσετε τον χειρισμό συνδέσμων.
- **Desktop**: Στο Linux AppImage, βεβαιωθείτε ότι είναι εγκατεστημένα τα GTK 3 και `webkit2gtk-4.1` (`libwebkit2gtk-4.1-0` σε Debian/Ubuntu, `webkit2gtk4.1` σε Fedora, `webkit2gtk-4.1` σε Arch).
- **Επέκταση**: Καρφιτσώστε την επέκταση Nori στη γραμμή εργαλείων του προγράμματος περιήγησής σας για γρήγορη προσθήκη σελιδοδεικτών και αναζήτηση με ένα κλικ.
- Συνεχίστε με την [Επισκόπηση](/el/nori/) για το πλαίσιο του προϊόντος ή τα [Χαρακτηριστικά](/el/nori/features/) για την πλήρη λίστα δυνατοτήτων.
