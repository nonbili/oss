## インストール後

- **モバイル**: Web ブラウザからシステムの共有メニューを使って Nori にリンクを共有し、正しく連携できるか試してください。
- **デスクトップ**: Linux AppImage を利用する場合、GTK 3 および `webkit2gtk-4.1` がインストールされていることを確認してください（Debian/Ubuntu では `libwebkit2gtk-4.1-0`、Fedora では `webkit2gtk4.1`、Arch では `webkit2gtk-4.1`）。
- **拡張機能**: ブラウザのツールバーに Nori 拡張機能をピン留めすると、1 クリックでのブックマーク保存や検索がスムーズになります。
- 概要については [Overview](/ja/nori/)、すべての機能一覧は [Features](/ja/nori/features/) を参照してください。
