Nori — это менеджер закладок и средство запуска с открытым исходным кодом, созданный для быстрого ежедневного доступа к ссылкам на мобильных устройствах, компьютерах и в веб-браузерах.

Вместо того чтобы прятать ссылки в глубоких папках браузера или закрытых экосистемах, Nori организует ваши закладки в понятные структурированные списки с мгновенным запуском, поиском, наглядными карточками предпросмотра и интеграцией с системным меню «Поделиться».

## Основные возможности

- Несколько пользовательских списков закладок
- Мгновенный запуск в системном браузере по умолчанию или во встроенных вкладках
- Сохранение ссылок из любых приложений с выбором списка и быстрым сохранением
- Компактный режим запуска и режим карточек предпросмотра с обложками сайтов
- Быстрая панель поиска с фильтрацией по ключевым словам и тегам
- История запуска: недавние и недавно добавленные ссылки
- Импорт и экспорт через стандартные файлы HTML, обычный текст и полные резервные копии JSON
- Гибкая настройка внешнего вида: Светлая, Тёмная, AMOLED темы и выбор цвета акцента
- Локальное расширение для Chrome и Firefox
- Кроссплатформенное приложение для Linux, macOS и Windows
- Синхронизация между устройствами через Nori Sync

## Платформы

- **Android**: Доступно в Google Play и в виде прямых APK-релизов на GitHub.
- **iOS**: Доступно в App Store для iPhone и iPad.
- **Десктоп**: Отдельные нативные приложения для Linux (AppImage и tarball), macOS (Apple Silicon и Intel) и Windows.
- **Браузерное расширение**: Расширение Manifest V3 для Mozilla Firefox и Google Chrome.

## Первый запуск

Рекомендуемый порядок начальной настройки:

1. Создайте несколько списков для основных категорий ссылок (например, `Ежедневное`, `Инструменты`, `Чтение`, `Работа`).
2. Добавьте свои основные ссылки или импортируйте существующие закладки из HTML-файла браузера.
3. Попробуйте запустить закладку, чтобы убедиться, что браузер по умолчанию открывает ссылки корректно.
4. Отправьте веб-страницу из мобильного браузера в Nori через системное меню «Поделиться».
5. Настройте внешний вид, выбрав тёмную тему или любимый цвет акцента.

## Как это работает

Nori отделяет вашу коллекцию закладок от конкретных браузерных движков:

- На Android закладки открываются через Custom Tabs с помощью `expo-web-browser` или напрямую передаются в браузер по умолчанию.
- На iOS ссылки открываются через встроенное окно браузера или в системном браузере.
- На десктопе и в расширении ссылки открываются прямо во вкладках активного браузера.

Такой подход позволяет использовать привычные блокировщики рекламы, сохранённые учетные записи и профили браузера, сохраняя все ссылки в едином, быстром и удобном лаунчере.
