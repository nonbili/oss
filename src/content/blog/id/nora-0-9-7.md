Dengan **Nora 0.9.7 untuk seluler**, Anda dapat mengirim unduhan Android ke folder pilihan Anda dan merampingkan menu tiga titik peramban hanya ke tindakan yang Anda gunakan. Rilis ini juga membuka WhatsApp Web dan Facebook Marketplace dalam mode desktop secara otomatis.

## Pilih Tempat Menyimpan Unduhan

Di Android, buka **Setelan → Preferensi → Unduhan → Simpan unduhan ke** untuk menentukan lokasi penyimpanan unduhan peramban.

- **Unduhan** menggunakan folder Unduhan standar Android.
- **Tanya setiap kali** memungkinkan Anda memilih tujuan untuk setiap unduhan.
- **Pilih folder…** menyimpan unduhan mendatang ke folder yang Anda pilih.

Jika Anda memilih sebuah folder, Nora juga menggunakannya untuk media yang Anda simpan dari feed di Android 10 dan yang lebih baru. Rilis ini juga memperbaiki unduhan dari tautan `data:`, yang digunakan oleh beberapa situs untuk file yang dibuat di peramban.

![Setelan unduhan Android dengan Nora Downloads dipilih serta opsi Unduhan, Tanya setiap kali, dan Pilih folder terlihat](/blog/nora-0-9-7/download-destination.webp "Nora Downloads dipilih sebagai tujuan untuk unduhan mendatang.")

## Sesuaikan Menu Tiga Titik

Buka **Setelan → Tampilan → Bilah Alat → Sesuaikan menu tiga titik** lalu matikan tindakan yang jarang Anda gunakan. Misalnya, pertahankan **Cari di halaman** dan **Bagikan**, lalu sembunyikan **Situs desktop** jika Anda jarang mengganti tata letak. Tindakan yang Anda pertahankan akan muncul saat tersedia di tab saat ini.

**Setelan** tetap berada di menu, dan **Pulihkan default menu** menghapus perubahan Anda dalam satu ketukan.

![Setelan Sesuaikan menu tiga titik yang diperluas dengan Cari di halaman aktif dan Situs desktop nonaktif](/blog/nora-0-9-7/customize-three-dot-menu.webp "Biarkan Cari di halaman tetap aktif dan matikan Situs desktop.")
![Menu peramban yang telah disesuaikan menampilkan Cari di halaman, Bagikan, dan Setelan, dengan Situs desktop disembunyikan](/blog/nora-0-9-7/customized-three-dot-menu.webp "Menu peramban mempertahankan Cari di halaman, Bagikan, dan Setelan.")

## WhatsApp Web dan Facebook Marketplace Terbuka di Mode Desktop

Di **WhatsApp Web**, keyboard di layar kini dapat terbuka tanpa menutup pemilih. **Facebook Marketplace** menggunakan situs desktop agar Anda dapat mengirim pesan kepada penjual langsung dari daftar iklan.

## Perbaikan Penjelajahan dan Feed

- Pemblokiran iklan Facebook kini menangkap postingan bersponsor meskipun labelnya muncul terlambat. Menekan lama tombol reaksi Facebook tidak lagi memunculkan menu konteks peramban.
- Filter game Reddit tetap menampilkan postingan biasa.
- Pengalih tab terbuka dengan tab aktif Anda terlihat. Di tab baru, alamat yang diketik terbuka pada ketukan pertama **Buka**, dan membuka tautan masuk tetap mempertahankan tab Anda yang lain.
- Tarik untuk menyegarkan tidak mengganggu saat Anda melakukan gestur di dalam penampil media.
