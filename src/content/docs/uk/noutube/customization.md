NouTube підтримує власний CSS для вбудованих сторінок YouTube та YouTube Music.

## Для чого корисний власний CSS

- Приховування елементів, які вам не потрібні
- Ущільнення макета сторінки
- Коригування відступів або типографіки
- Обхід рішень інтерфейсу сайту, які вам заважають

## Рекомендований підхід

Робіть зміни вузькими та такими, що легко прибираються.

- Починайте з одного чи двох точкових правил
- За можливості надавайте перевагу стабільним селекторам
- Повторно тестуйте після змін макета на боці сайту

Оскільки NouTube обгортає живі вебресурси, власний CSS може перестати працювати, коли YouTube змінює свою розмітку.

## Перш ніж налаштовувати

Переконайтеся, що стандартна поведінка програми вже працює для:

- Відтворення
- Навігації
- Стрічок
- Завантажень

Коли основа працює стабільно, додавайте зміни CSS поступово.
