Nora підтримує власний CSS, щоб ви могли змінювати вигляд вебсайтів сервісів, які вона вбудовує.

## Поширені сценарії використання

- Приховування відволікаючих елементів інтерфейсу
- Підвищення щільності відображення для макетів із насиченими стрічками
- Видалення елементів оформлення сервісів, якими ви ніколи не користуєтеся
- Зручніше сканування багатоколонкових макетів на комп'ютері

## Підтримуйте зміни в актуальному стані

Оскільки Nora залежить від живих вебсайтів зовнішніх сервісів, їхня розмітка може змінитися без попередження.

Використовуйте обережний підхід:

- Надавайте перевагу невеликим, точковим правилам
- Повторно тестуйте після редизайну сервісів
- Уникайте широких перевизначень, якщо не контролюєте їхні наслідки

## Поєднуйте CSS із профілями

Якщо ви використовуєте окремі профілі для різних сервісів або ролей, тримайте налаштування CSS узгодженими з цими профілями, щоб поведінка залишалася передбачуваною.
