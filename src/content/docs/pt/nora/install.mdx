## Após a instalação

- Abra uma das suas ligações sociais habituais no Nora se o seu dispositivo perguntar qual a aplicação a utilizar.
- Inicie sessão nos serviços que mais utiliza e confirme primeiro que a navegação normal funciona.
- Continue com [Visão geral](/pt/nora/) para o contexto do produto, ou [Funcionalidades](/pt/nora/features/) para a lista completa de capacidades.
