## 安装后说明

- **移动端**：尝试从 Web 浏览器通过系统分享菜单向 Nori 分享链接，以验证链接接收功能。
- **桌面端**：在 Linux AppImage 上，请确保已安装 GTK 3 和 `webkit2gtk-4.1`（Debian/Ubuntu 上为 `libwebkit2gtk-4.1-0`，Fedora 上为 `webkit2gtk4.1`，Arch 上为 `webkit2gtk-4.1`）。
- **扩展**：将 Nori 扩展固定到浏览器工具栏，以便一键添加书签和快速搜索。
- 继续阅读 [概览](/zh-hans/nori/) 了解产品背景，或查看 [功能](/zh-hans/nori/features/) 获取完整特性列表。
