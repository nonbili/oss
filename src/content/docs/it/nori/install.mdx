## Dopo l'installazione

- **Mobile**: Prova a condividere un link dal tuo browser web verso Nori tramite il menu di condivisione di sistema per verificarne la gestione.
- **Desktop**: Su Linux (AppImage), assicurati che siano installati GTK 3 e `webkit2gtk-4.1` (`libwebkit2gtk-4.1-0` su Debian/Ubuntu, `webkit2gtk4.1` su Fedora, `webkit2gtk-4.1` su Arch).
- **Estensione**: Fissa l'estensione Nori sulla barra degli strumenti del browser per salvare e cercare segnalibri con un solo clic.
- Continua con la [Panoramica](/it/nori/) per il contesto del prodotto o con le [Funzionalità](/it/nori/features/) per l'elenco completo delle funzionalità.
