## Pengorganisasian Daftar

- **Beberapa daftar**: Pisahkan tautan ke dalam kategori terarah seperti Medsos, Kerja, Bacaan, Berita, atau alat AI.
- **Manajemen daftar**: Buat, ubah nama, sembunyikan, atau hapus daftar sesuai kebutuhan alur kerja Anda.
- **Tarik untuk menyusun ulang**: Atur urutan daftar dan markah persis seperti yang Anda inginkan dengan mudah.
- **Pindahkan dan hapus massal**: Pilih beberapa markah untuk dipindahkan antar-daftar atau membersihkan item yang usang.

## Peluncuran dan Penjelajahan

- **Pengalihan ke browser default**: Buka markah langsung di aplikasi browser sistem pilihan Anda.
- **Custom Tabs dalam aplikasi**: Di Android dan iOS, tersedia opsi Custom Tabs tersemat atau Safari View Controller untuk pratinjau cepat tanpa berganti aplikasi.
- **Pengambilan favicon situs**: Mengambil favicon domain secara otomatis, dengan opsi menampilkan ikon Nori yang bersih dan konsisten.

## Integrasi Menu Berbagi Sistem

- **Penerima berbagi sistem**: Kirim tautan ke Nori langsung dari menu berbagi browser web, aplikasi chat, atau pembaca dokumen mana pun.
- **Pilihan daftar tujuan**: Tentukan daftar tujuan saat menyimpan tautan.
- **Mode simpan cepat**: Atur daftar tujuan default untuk langsung menyimpan tautan masuk tanpa dialog konfirmasi.
- **Judul halaman otomatis**: Mengambil judul halaman web secara otomatis saat menambahkan tautan.

## Mode Tampilan

- **Peluncur ringkas**: Tombol efisien yang dioptimalkan untuk peluncuran satu ketukan dan kepadatan informasi tinggi.
- **Kartu pratinjau**: Kartu visual kaya informasi yang menampilkan gambar sampul situs dan ringkasan deskripsi.
- **Kepadatan tata letak**: Pilih antara tata letak 1 kolom dan kisi 2 kolom sesuai ukuran layar dan preferensi membaca Anda.

## Panel Pencarian dan Riwayat

- **Pencarian cepat**: Filter semua markah secara real-time berdasarkan judul, URL, atau tag kustom.
- **Opsi pengurutan**: Urutkan markah berdasarkan terbaru, terlama, nama (A–Z), atau kebalikannya (Z–A).
- **Baru saja digunakan**: Buka kembali tautan yang baru saja Anda luncurkan tanpa perlu mencarinya di dalam daftar.
- **Baru saja ditambahkan**: Lihat tautan yang baru ditambahkan dalam sekejap.

## Impor, Ekspor, dan Cadangan

- **Impor HTML browser**: Impor file markah HTML standar yang diekspor dari Chrome, Firefox, Safari, Edge, atau Brave.
- **Ekspor teks biasa**: Ekspor daftar judul dan URL yang mudah dibaca untuk keperluan catatan dan dokumentasi.
- **Cadangan penuh dan pemulihan**: Simpan file cadangan JSON portabel berisi seluruh konfigurasi, daftar, dan markah Anda untuk penyimpanan aman.

## Sinkronisasi Cloud

- **Sinkronisasi multiperangkat**: Sinkronisasi cloud opsional melalui Nori Sync untuk menjaga daftar dan markah tetap terbarui di ponsel, tablet, desktop, dan ekstensi browser Anda.
- **Fondasi lokal-utama**: Semua markah tetap tersimpan secara lokal di perangkat Anda, menjamin ketersediaan penuh bahkan tanpa koneksi internet aktif.
