## Kā saglabāt saites lietotnē Nori no mobilā pārlūka?

Izmantojiet standarta sistēmas kopīgošanas izvēlni:

1. Savā pārlūkā (Chrome, Firefox, Safari, Brave u.c.) pieskarieties **Kopīgot**.
2. Lietotņu sarakstā atlasiet **Nori**.
3. Izvēlieties mērķa sarakstu, kurā vēlaties saglabāt saiti, vai iestatījumos iespējojiet **Ātri saglabāt kopīgotās saites**, lai saglabātu tieši norādītajā sarakstā bez uzvednes.

## Vai varu atvērt grāmatzīmes tieši savā pārlūka lietotnē, nevis lietotnes iekšējā cilnē?

Jā. Dodieties uz **Iestatījumi → Vispārīgi** un ieslēdziet **Atvērt saites noklusējuma pārlūkā**. Kad tas ir iespējots, pieskaroties jebkurai grāmatzīmei, URL nekavējoties tiks nodots tālruņa noklusējuma pārlūka lietotnei.

## Kā importēt grāmatzīmes no datora pārlūkiem?

Eksportējiet esošās grāmatzīmes uz HTML failu:

- **Chrome / Brave / Edge**: atveriet Grāmatzīmju pārvaldnieku (`Ctrl+Shift+O` vai `Cmd+Option+B`) → noklikšķiniet uz izvēlnes `⋮` → atlasiet **Eksportēt grāmatzīmes**.
- **Firefox**: atveriet Bibliotēku (`Ctrl+Shift+O` vai `Cmd+Shift+O`) → **Importēšana un dublēšana** → **Eksportēt grāmatzīmes kā HTML…**.
- **Safari**: Fails → **Eksportēt grāmatzīmes…**.

Pēc tam lietotnē Nori dodieties uz **Iestatījumi → Grāmatzīmes → Importēt grāmatzīmes**, atlasiet `.html` failu, un Nori importēs visas saites un mapes atbilstošajos sarakstos.

## Vai varu dublēt un atjaunot savas grāmatzīmes?

Jā. Sadaļā **Iestatījumi → Grāmatzīmes**:

- **Eksportēt dublējumu**: saglabā pilnu JSON dublējuma failu ar visiem sarakstiem, grāmatzīmēm, birkām un iestatījumiem.
- **Atjaunot dublējumu**: atjauno no esoša Nori dublējuma faila.
- **Eksportēt HTML / Vienkāršu tekstu**: izveido pārlūkam saderīgu HTML failu vai lasāmu teksta sarakstu.

## Kā darbojas vairāku ierīču sinhronizācija?

Nori Sync savieno jūsu mobilās lietotnes, datora lietotnes un pārlūka paplašinājumus:

- Grāmatzīmes paliek kešatmiņā lokāli katrā ierīcē pilnīgai darbībai bezsaistē.
- Kad ir savienojums, izmaiņas nemanāmi sinhronizējas starp visiem aktīvajiem klientiem.

## Vai pārlūka paplašinājums izseko manu pārlūkošanas darbību?

Nē. Nori neuzrauga jūsu pārlūkošanas vēsturi un nelasa tīmekļa lapu saturu. Paplašinājums saņem URL tikai tad, kad atverat uznirstošo logu un noklikšķināt, lai pievienotu pašreizējo cilni grāmatzīmēm.
