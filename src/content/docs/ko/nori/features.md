## 목록 정리

- **다중 목록**: SNS, 업무, 읽기, 뉴스, AI 도구 등 집중된 카테고리로 링크를 구분하세요.
- **목록 관리**: 작업 흐름의 변화에 따라 목록을 생성, 이름 변경, 숨기기 또는 삭제할 수 있습니다.
- **드래그로 순서 변경**: 목록과 북마크를 원하는 정확한 순서로 배치하세요.
- **일괄 이동 및 삭제**: 여러 북마크를 선택해 목록 간에 이동하거나 오래된 항목을 정리하세요.

## 실행 및 브라우징

- **기본 브라우저 전달**: 선호하는 시스템 브라우저 앱에서 북마크를 바로 엽니다.
- **인앱 커스텀 탭**: Android 및 iOS에서는 앱 전환 없이 빠르게 훑어볼 수 있도록 내장 Custom Tabs 또는 Safari View Controller 시트를 선택적으로 사용할 수 있습니다.
- **파비콘 불러오기**: 도메인 파비콘을 자동으로 가져오며, 깔끔한 Nori 아이콘을 대신 표시하는 옵션도 제공합니다.

## 공유 시트 연동

- **시스템 공유 수신기**: 모든 웹 브라우저, 채팅 앱 또는 리더의 공유 메뉴에서 Nori로 링크를 바로 보냅니다.
- **대상 목록 선택**: 저장하는 즉시 대상 목록을 고를 수 있습니다.
- **빠른 저장 모드**: 기본 대상 목록을 설정해 확인 창 없이 들어오는 링크를 즉시 저장합니다.
- **자동 페이지 제목**: 링크를 추가할 때 웹페이지 제목을 자동으로 가져옵니다.

## 보기 모드

- **컴팩트 런처**: 한 번의 탭으로 실행하고 높은 정보 밀도를 제공하도록 최적화된 간결한 버튼입니다.
- **미리보기 카드**: 웹사이트 커버 이미지와 설명 요약이 포함된 풍부한 시각적 카드입니다.
- **레이아웃 밀도**: 화면 크기와 읽기 스타일에 맞춰 1열과 2열 레이아웃 중 선택하세요.

## 검색 서랍 및 기록

- **빠른 검색**: 제목, URL 또는 사용자 지정 태그로 모든 북마크를 실시간 필터링합니다.
- **정렬 옵션**: 최신순, 오래된순, 이름순(A–Z) 또는 역알파벳순(Z–A)으로 북마크를 정렬합니다.
- **최근 사용**: 목록을 뒤지지 않고 최근에 실행한 북마크를 빠르게 다시 엽니다.
- **최근 추가**: 새로 추가한 항목을 한눈에 확인합니다.

## 가져오기, 내보내기 및 백업

- **브라우저 HTML 가져오기**: Chrome, Firefox, Safari, Edge 또는 Brave에서 내보낸 표준 HTML 북마크 파일을 가져옵니다.
- **일반 텍스트 내보내기**: 메모 및 문서화를 위해 사람이 읽기 쉬운 제목과 URL 목록을 내보냅니다.
- **전체 백업 및 복원**: 전체 구성, 목록 및 북마크의 포터블 JSON 백업을 안전하게 저장합니다.

## 클라우드 동기화

- **다중 기기 동기화**: Nori Sync를 통한 선택적 클라우드 동기화로 휴대전화, 태블릿, 데스크톱 및 브라우저 확장 프로그램 전반에서 목록과 북마크를 최신 상태로 유지합니다.
- **로컬 우선 기반**: 모든 북마크는 기기에 로컬로 캐시되어 활성 인터넷 연결이 없어도 완벽한 오프라인 사용을 보장합니다.
