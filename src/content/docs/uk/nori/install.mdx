## Після встановлення

- **Мобільні пристрої**: спробуйте поділитися посиланням із веббраузера в Nori через системне меню поширення, щоб перевірити обробку посилань.
- **Комп'ютери**: для Linux AppImage переконайтеся, що встановлено GTK 3 і `webkit2gtk-4.1` (`libwebkit2gtk-4.1-0` у Debian/Ubuntu, `webkit2gtk4.1` у Fedora, `webkit2gtk-4.1` в Arch).
- **Розширення**: закріпіть розширення Nori на панелі інструментів браузера для швидкого додавання закладок і пошуку в один клік.
- Перейдіть до [Огляду](/uk/nori/), щоб дізнатися більше про продукт, або до [Можливостей](/uk/nori/features/), щоб переглянути повний список функцій.
