## Tras la instalación

- **Móvil**: Prueba a compartir un enlace desde tu navegador web hacia Nori usando el menú compartir para verificar la integración.
- **Escritorio**: En Linux (AppImage), asegúrate de que GTK 3 y `webkit2gtk-4.1` estén instalados (`libwebkit2gtk-4.1-0` en Debian/Ubuntu, `webkit2gtk4.1` en Fedora, `webkit2gtk-4.1` en Arch).
- **Extensión**: Fija la extensión de Nori en la barra de herramientas del navegador para guardar y buscar marcadores con un solo clic.
- Continúa con la [Información general](/es/nori/) para el contexto del producto o las [Características](/es/nori/features/) para la lista completa de funcionalidades.
