## Организация списков

- **Несколько списков**: Разделяйте ссылки по тематическим категориям, таким как соцсети, работа, чтение, новости или инструменты ИИ.
- **Управление списками**: Создавайте, переименовывайте, скрывайте или удаляйте списки по мере необходимости.
- **Перетаскивание для сортировки**: Упорядочивайте списки и закладки в нужном вам порядке перетаскиванием.
- **Массовое перемещение и удаление**: Выбирайте несколько закладок для перемещения между списками или удаления устаревших ссылок.

## Запуск и просмотр

- **Открытие в браузере по умолчанию**: Запускайте закладки напрямую в системном браузере вашего устройства.
- **Встроенные вкладки**: На Android и iOS можно использовать встроенные Custom Tabs или Safari View Controller для быстрого просмотра без переключения между приложениями.
- **Значки сайтов (Favicon)**: Автоматическая загрузка фавиконов с возможностью переключения на лаконичный значок Nori.

## Интеграция с меню «Поделиться»

- **Системный приёмник ссылок**: Отправляйте ссылки в Nori прямо из меню «Поделиться» любого браузера, мессенджера или читалки.
- **Выбор целевого списка**: Указывайте нужный список непосредственно при сохранении.
- **Режим быстрого сохранения**: Назначьте список по умолчанию для мгновенного сохранения входящих ссылок без лишних запросов.
- **Автоматические заголовки страниц**: Автоматическое определение названия веб-страницы при добавлении ссылки.

## Режимы отображения

- **Компактный лаунчер**: Лаконичные кнопки, оптимизированные для запуска в одно касание и высокой плотности информации.
- **Карточки предпросмотра**: Наглядные визуальные карточки с обложками веб-страниц и фрагментами описания.
- **Плотность макета**: Переключение между 1-колоночным и 2-колоночным отображением в зависимости от размера экрана.

## Панель поиска и история

- **Быстрый поиск**: Фильтрация всех закладок по названию, URL или пользовательским тегам в реальном времени.
- **Параметры сортировки**: Сортировка закладок по дате добавления (новые/старые) или по алфавиту (А–Я / Я–А).
- **Недавние**: Быстрое повторное открытие недавно запущенных ссылок без поиска по спискам.
- **Недавно добавленные**: Просмотр последних сохранённых ссылок на отдельной вкладке.

## Импорт, экспорт и резервное копирование

- **Импорт HTML из браузеров**: Импорт стандартных файлов закладок HTML, экспортированных из Chrome, Firefox, Safari, Edge или Brave.
- **Экспорт в обычный текст**: Экспорт читаемого списка названий и URL для заметок и документации.
- **Полное резервное копирование и восстановление**: Сохранение полного бэкапа в формате JSON со всеми списками, закладками и настройками.

## Облачная синхронизация

- **Синхронизация между устройствами**: Дополнительная синхронизация через Nori Sync для обновления списков и закладок на телефоне, планшете, компьютере и в расширении браузера.
- **Локальная работа (Local-first)**: Все закладки кэшируются локально на устройстве, обеспечивая полную доступность даже без подключения к сети.
