NouTube는 포함된 YouTube 및 YouTube Music 페이지에 대한 사용자 지정 CSS를 지원합니다.

## 사용자 지정 CSS의 활용

- 신경 쓰지 않는 요소 숨기기
- 페이지 밀도 높이기
- 여백 또는 타이포그래피 조정
- 방해가 되는 사이트 UI 구성 우회하기

## 권장 접근 방식

변경 사항은 범위를 좁히고 제거하기 쉽게 유지하세요.

- 한두 개의 대상이 명확한 규칙으로 시작
- 가능하면 안정적인 선택자 우선 사용
- 원본 사이트 레이아웃 변경 후 다시 테스트

NouTube는 실제 웹 사이트를 감싸서 실행하므로 YouTube가 마크업을 변경하면 사용자 지정 CSS가 깨질 수 있습니다.

## 사용자 지정 전에

먼저 기본 앱 동작이 다음 항목에서 정상 작동하는지 확인하세요:

- 재생
- 탐색
- 피드
- 다운로드

기본 동작이 안정적일 때 CSS 변경 사항을 점진적으로 추가하세요.
