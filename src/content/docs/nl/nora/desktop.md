Nora wordt uitgebracht als desktop-app voor Linux, macOS en Windows.

## Wat Desktop toevoegt

De desktopversie voegt een indeling toe die is ontworpen voor grotere schermen, waaronder een deck-weergave om meerdere tijdlijnen comfortabeler te volgen.

Dat maakt de desktopversie de betere keuze wanneer je:

- Meerdere feeds tegelijk volgt
- Aparte werkruimten openhoudt voor verschillende accounts of diensten
- Wilt dat Nora fungeert als een vaste dagelijkse browser in plaats van een snelle mobiele tool

## Wat je kunt verwachten

Desktop behoudt hetzelfde algemene productmodel als mobiel:

- Open ondersteunde sociale sites in één app
- Gebruik accountscheiding en browsetools op een groter scherm
- Installeer native pakketten voor Linux, macOS of Windows
