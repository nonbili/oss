Nora는 소셜 네트워크 서비스에 최적화된 Android, iOS 및 데스크톱 브라우저입니다.

원본 서비스 웹사이트를 그대로 유지하면서 분리된 계정 저장소, 차단 목록, 다운로드 도구, URL 정리, CSS 사용자 지정 같은 네이티브 편의 기능을 더했습니다.

## 주요 특징

- 광고 없음
- 별도의 쿠키 저장소를 사용하는 다중 계정
- EasyList 및 EasyPrivacy 차단 목록 지원
- 미디어 다운로드
- 텍스트 선택 및 확대/축소
- URL에서 추적 쿼리 매개변수 제거
- 사용자 지정 CSS 지원

## 처음 실행 시

권장하는 초기 설정 순서는 다음과 같습니다:

1. 가장 자주 사용하는 서비스를 엽니다.
2. 로그인한 뒤 Nora 안에서 웹 흐름이 정상 작동하는지 확인합니다.
3. 계정을 엄격하게 분리하려면 추가 프로필을 만듭니다.
4. 차단 목록을 활성화하고 자주 쓰는 서비스에서 미디어 다운로드 동작을 테스트합니다.
5. 기본 브라우징 흐름이 안정된 후에만 사용자 지정 CSS를 추가합니다.

## 작동 방식

Nora는 각 네트워크를 네이티브 클라이언트로 다시 구현하는 대신 서비스 웹사이트를 감싸서 실행합니다.

이 방식 덕분에 사이트를 익숙한 모습 그대로 유지하면서 다음 기능을 추가할 수 있습니다:

- 광고 차단
- 계정 간 쿠키 격리
- 미디어 다운로드 흐름
- 서비스별 개선 기능
