## 如何从手机浏览器中将链接保存到 Nori？

使用系统标准分享菜单：

1. 在浏览器（Chrome、Firefox、Safari、Brave 等）中，点击 **分享**。
2. 在应用列表中选择 **Nori**。
3. 选择保存该链接的目标列表，或者在设置中开启“快速保存分享的链接”，无需确认即可直接保存到指定列表。

## 可以直接在浏览器应用中打开书签而不是应用内标签页吗？

可以。进入 **设置 → 通用** 并开启 **在默认浏览器中打开链接**。启用后，点击任何书签都会立即跳转到手机的默认浏览器应用中打开。

## 如何从桌面端浏览器导入书签？

将现有的书签导出为 HTML 文件：

- **Chrome / Brave / Edge**：打开书签管理器（`Ctrl+Shift+O` 或 `Cmd+Option+B`）→ 点击 `⋮` 菜单 → 选择 **导出书签**。
- **Firefox**：打开我的足迹/管理书签（`Ctrl+Shift+O` 或 `Cmd+Shift+O`）→ **导入和备份** → **导出书签到 HTML…**。
- **Safari**：文件 → **导出书签…**。

然后在 Nori 中进入 **设置 → 书签 → 导入书签**，选择该 `.html` 文件，Nori 会将所有链接和文件夹导入到对应的列表中。

## 可以备份和恢复书签吗？

可以。在 **设置 → 书签** 中：

- **导出备份**：保存包含所有列表、书签、标签和设置的完整 JSON 备份文件。
- **恢复备份**：从已有的 Nori 备份文件进行恢复。
- **导出 HTML / 纯文本**：生成兼容浏览器的 HTML 文件或易读的纯文本列表。

## 多设备同步是如何工作的？

Nori Sync 将您的移动应用、桌面应用和浏览器扩展连接在一起：

- 书签在每台设备上都有完整的本地缓存，完全支持离线使用。
- 连接网络时，所做的更改会在所有处于活动状态的客户端之间无缝同步。

## 浏览器扩展会跟踪我的浏览活动吗？

不会。Nori 不会监控您的浏览历史，也不会读取网页内容。扩展仅在您主动打开弹出窗口并点击收藏当前标签页时接收网址。
