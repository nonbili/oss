## После установки

- **Мобильные устройства**: Попробуйте поделиться ссылкой из браузера в Nori через системное меню «Поделиться», чтобы проверить перехват ссылок.
- **Десктоп**: Для Linux AppImage убедитесь, что установлены GTK 3 и `webkit2gtk-4.1` (`libwebkit2gtk-4.1-0` в Debian/Ubuntu, `webkit2gtk4.1` в Fedora, `webkit2gtk-4.1` в Arch).
- **Расширение**: Закрепите расширение Nori на панели инструментов браузера для быстрого добавления закладок и поиска в один клик.
- Продолжите с [Обзора](/ru/nori/) для ознакомления с продуктом или [Функций](/ru/nori/features/) для получения полного списка возможностей.
