Nora는 포함된 서비스 웹사이트의 모양을 직접 바꿀 수 있도록 사용자 지정 CSS를 지원합니다.

## 일반적인 활용

- 방해되는 UI 숨기기
- 타임라인 중심 레이아웃의 밀도 개선
- 사용하지 않는 서비스별 인터페이스 요소 제거
- 데스크톱 다중 열 구성을 더 한눈에 보기 쉽게 조정

## 변경 사항을 유지보수하기 쉽게 유지하기

Nora는 외부 서비스의 실제 웹사이트에 의존하므로 원본 마크업이 예고 없이 변경될 수 있습니다.

보수적인 접근 방식을 권장합니다:

- 작고 대상이 명확한 규칙을 우선 사용
- 서비스 디자인 개편 후 다시 테스트
- 영향 범위를 제어할 수 없다면 광범위한 재정의는 피하기

## 프로필과 CSS 함께 사용하기

서비스나 역할별로 별도의 프로필을 사용하는 경우, 동작이 예측 가능하도록 해당 프로필에 맞춰 CSS 조정을 유지하세요.
