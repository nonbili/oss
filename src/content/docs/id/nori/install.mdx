## Setelah Instalasi

- **Seluler**: Coba bagikan tautan dari browser web Anda ke Nori menggunakan menu berbagi sistem untuk memverifikasi penanganan tautan.
- **Desktop**: Pada Linux AppImage, pastikan GTK 3 dan `webkit2gtk-4.1` terpasang (`libwebkit2gtk-4.1-0` di Debian/Ubuntu, `webkit2gtk4.1` di Fedora, `webkit2gtk-4.1` di Arch).
- **Ekstensi**: Sematkan ekstensi Nori ke bilah alat browser Anda untuk kemudahan bookmark satu klik dan pencarian cepat.
- Lanjutkan ke [Ikhtisar](/id/nori/) untuk konteks produk, atau [Fitur](/id/nori/features/) untuk daftar kapabilitas lengkap.
