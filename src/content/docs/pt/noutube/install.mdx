## Após a instalação

- **Telemóvel**: Abra uma ligação do YouTube ou YouTube Music no NouTube se o seu dispositivo perguntar qual a aplicação a utilizar. No iOS, junte-se à versão beta através do TestFlight.
- **Computador**: Confirme que a reprodução funciona como espera antes de alterar definições avançadas.
- **Extensão**: Afixe a extensão NouTube na barra de ferramentas do seu navegador ou consulte [Extensão de navegador](/pt/noutube/extension/) para mais detalhes.
- Continue com [Visão geral](/pt/noutube/) para o contexto do produto, ou [Funcionalidades](/pt/noutube/features/) para a lista completa de capacidades.
