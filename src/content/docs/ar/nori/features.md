## تنظيم القوائم

- **قوائم متعددة**: تقسيم الروابط إلى فئات مخصصة مثل وسائل التواصل، العمل، القراءة، الأخبار، أو أدوات الذكاء الاصطناعي.
- **إدارة القوائم**: إنشاء القوائم وإعادة تسميتها وإخفاؤها وحذفها وفقًا لاحتياجاتك.
- **السحب لإعادة الترتيب**: ترتيب القوائم والإشارات المرجعية بالترتيب الذي تفضله بدقة.
- **النقل والحذف المتعدد**: تحديد إشارات مرجعية متعددة لنقلها بين القوائم أو حذف العناصر القديمة دفعة واحدة.

## التشغيل والتصفح

- **التحويل إلى متصفح النظام**: فتح الإشارات المرجعية مباشرة في متصفح النظام المفضل لديك.
- **علامات تبويب مخصصة داخل التطبيق**: على Android و iOS، يتوفر خيار استخدام Custom Tabs أو Safari View Controller للاطلاع السريع دون مغادرة التطبيق.
- **جلب أيقونة الموقع (Favicon)**: جلب أيقونات المواقع تلقائيًا مع خيار عرض أيقونة Nori الأنيقة والموحدة بدلاً منها.

## التكامل مع قائمة المشاركة

- **مستقبل مشاركة النظام**: إرسال الروابط إلى Nori مباشرة من قائمة المشاركة في أي متصفح ويب، أو تطبيق دردشة، أو قارئ أخبار.
- **تحديد القائمة المستهدفة**: اختيار القائمة المطلوبة فور حفظ الرابط.
- **وضع الحفظ السريع**: تعيين قائمة مستهدفة افتراضية لحفظ الروابط الواردة مباشرة دون مطالبات تأكيد.
- **عناوين الصفحات التلقائية**: جلب عنوان صفحة الويب تلقائيًا عند إضافة الروابط.

## أوضاع العرض

- **المشغل المضغوط**: أزرار مدمجة ومحسنة للتشغيل بنقرة واحدة وتوفير كثافة معلومات عالية.
- **بطاقات المعاينة**: بطاقات بصرية غنية تتضمن صورة غلاف الموقع ومقتطفات من الوصف.
- **كثافة التخطيط**: الاختيار بين تخطيط العمود الواحد والشبكة ذات العمودين بما يناسب حجم شاشتك وأسلوب قراءتك.

## درج البحث والسجل

- **البحث السريع**: تصفية فورية عبر جميع الإشارات المرجعية حسب العنوان، أو الرابط، أو الوسوم المخصصة في الوقت الفعلي.
- **خيارات الترتيب**: فرز الإشارات المرجعية حسب الأحدث، أو الأقدم، أو أبجديًا (A–Z)، أو عكسيًا (Z–A).
- **المستخدم مؤخرًا**: إعادة فتح الروابط التي تم تشغيلها مؤخرًا بسرعة دون الحاجة للبحث في القوائم.
- **المضاف حديثًا**: استعراض أحدث الإضافات بنظرة سريعة.

## الاستيراد والتصدير والنسخ الاحتياطي

- **استيراد HTML من المتصفحات**: استيراد ملفات إشارات HTML القياسية المصدرة من Chrome أو Firefox أو Safari أو Edge أو Brave.
- **تصدير نص عادي**: تصدير قائمة مقروءة بالعناوين والروابط لاستخدامها في الملاحظات والتوثيق.
- **نسخ احتياطي واستعادة كاملة**: حفظ نسخة احتياطية بصيغة JSON قابلة للنقل تحتوي على جميع إعداداتك وقوائمك وإشاراتك لحفظها بأمان.

## المزامنة السحابية

- **مزامنة متعددة الأجهزة**: مزامنة سحابية اختيارية عبر Nori Sync للحفاظ على تحديث القوائم والإشارات المرجعية عبر هاتفك وجهازك اللوحي وسطح المكتب وامتداد المتصفح.
- **بنية محلية أولاً**: تبقى جميع الإشارات المرجعية مخزنة محليًا على جهازك، مما يضمن العمل دون اتصال بالإنترنت في أي وقت.
