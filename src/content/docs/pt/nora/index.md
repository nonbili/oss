O Nora é um navegador para Android, iOS e computador otimizado para serviços de redes sociais.

Mantém os sites originais dos serviços enquanto adiciona conveniências nativas como armazenamento de contas separado, listas de bloqueio, ferramentas de transferência, limpeza de URLs e personalização de CSS.

## Destaques

- Sem anúncios
- Múltiplas contas com armazenamento de cookies separado
- Suporte às listas de bloqueio EasyList e EasyPrivacy
- Transferências de multimédia
- Selecionar texto e ampliar
- Remover parâmetros de rastreamento dos URLs
- Suporte para CSS personalizado

## Primeira utilização

Uma configuração inicial sensata é:

1. Abra o serviço que utiliza com mais frequência.
2. Inicie sessão e verifique se o fluxo web funciona normalmente dentro do Nora.
3. Crie perfis adicionais se pretender uma separação rigorosa entre contas.
4. Ative as listas de bloqueio e teste o comportamento de transferência de multimédia nos serviços que lhe interessam.
5. Adicione CSS personalizado apenas depois de o fluxo de navegação base estar estável.

## Como funciona

O Nora envolve os sites dos serviços em vez de reconstruir cada rede como um cliente nativo.

Essa abordagem mantém os sites familiares enquanto permite ao Nora adicionar:

- Bloqueio de anúncios
- Isolamento de cookies entre contas
- Fluxos de transferência de multimédia
- Melhorias específicas de cada serviço
