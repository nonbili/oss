Nora ist ein Android, iOS und Desktop Browser optimiert für soziale Netzwerkdienste.

Es behält die originalen Service-Websites bei und bietet gleichzeitig native Funktionen wie separate Kontenspeicherung, Blocklisten, Download-Tools, URL-Bereinigung und CSS-Anpassung an.

## Highlights

- Keine Werbung
- Mehrere Konten mit separater Cookie-Speicherung
- Unterstützung für EasyList und EasyPrivacy-Blocklisten.
- Medien-Downloads
- Text auswählen und zoomen
- Tracking-Parameter aus URLs entfernen
- Unterstützung für benutzerdefiniertes CSS

## Erster Start

Eine sinnvolle Erstkonfiguration sieht wie folgt aus:

1. Öffnen Sie den Dienst, den Sie am meisten nutzen.
2. Melden Sie sich an und überprüfen Sie, ob der Webflow in Nora ordnungsgemäß funktioniert.
3. Erstellen Sie zusätzliche Profile, wenn Sie eine strikte Trennung zwischen Konten bevorzugen.
4. Aktivieren Sie Blocklisten und testen Sie das Verhalten von Medien-Downloads auf den für Sie relevanten Diensten.
5. Fügen Sie benutzerdefiniertes CSS erst hinzu, wenn der grundlegende Browsing-Ablauf stabil ist.

## Wie es funktioniert

Nora bündelt die Service-Websites, anstatt jedes Netzwerk als eigenständigen Client neu aufzubauen.

Durch diesen Ansatz bleiben die Seiten gewohnt, während Nora folgendes hinzufügen kann:

- Werbeblockierung
- Cookie-Isolierung zwischen Konten
- Medien-Download-Abläufe
- Dienstspezifische Verbesserungen
