يوفر Nori تطبيق سطح مكتب مخصصًا لأنظمة Linux و macOS و Windows.

## ما يضيفه تطبيق سطح المكتب

ينقل إصدار سطح المكتب تجربة مشغل إشارات Nori المنظمة إلى حاسوبك كأداة سريعة وسهلة الاستخدام عبر لوحة المفاتيح:

- **مشغل مستقل**: تنظيم روابطك في نافذة منفصلة دون إرباك أشرطة علامات التبويب في المتصفح.
- **بنية محلية أولاً**: مبني باستخدام [Wails v3](https://v3.wails.io/) ولغة Go، ليجمع بين النوافذ الأصلية لنظام التشغيل وواجهات الويب الحديثة.
- **تشغيل في متصفح النظام**: النقر على الروابط يفتحها مباشرة في متصفح سطح المكتب الافتراضي لديك.
- **تكامل المزامنة**: ربط حساب Nori Sync الخاص بك لمشاركة الإشارات المرجعية بسلاسة بين سطح المكتب والهاتف وامتداد المتصفح.

## حزم المنصات

- **Linux**: يتم توزيعه كحزم AppImage محمولة وحزم `.tar.gz` لمعمارية `amd64`.
- **macOS**: دعم شامل لمعالجات Apple Silicon (`arm64`) و Intel (`amd64`)، موزع كملفات تثبيت `.dmg` وحزم `.app.zip`.
- **Windows**: يتم توزيعه كملفات تثبيت إعداد (`.exe`) وأرشيفات محمولة `.zip`.

## متطلبات نظام Linux

تستخدم حزمة AppImage لنظام Linux محرك WebKit الخاص بالنظام. تأكد من تثبيت GTK 3 و `webkit2gtk-4.1`:

- **Debian / Ubuntu**:
  ```bash
  sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0 libfuse2
  ```
- **Fedora**:
  ```bash
  sudo dnf install webkit2gtk4.1 gtk3
  ```
- **Arch Linux**:
  ```bash
  sudo pacman -S webkit2gtk-4.1 gtk3
  ```
