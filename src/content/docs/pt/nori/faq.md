## Como guardo ligações no Nori a partir do meu navegador móvel?

Utilize o menu de partilha padrão do sistema:

1. No seu navegador (Chrome, Firefox, Safari, Brave, etc.), toque em **Partilhar**.
2. Selecione **Nori** na lista de aplicações.
3. Escolha a lista de destino onde pretende guardar a ligação, ou ative **Gravação rápida de ligações partilhadas** nas definições para guardar diretamente numa lista designada sem confirmação.

## Posso abrir marcadores diretamente na aplicação do meu navegador em vez de um separador na aplicação?

Sim. Vá a **Definições → Geral** e ative **Abrir ligações no navegador predefinido**. Quando ativado, tocar em qualquer marcador entregará imediatamente o URL à aplicação de navegador predefinida do seu telemóvel.

## Como importo os meus marcadores de navegadores para computador?

Exporte os seus marcadores existentes para um ficheiro HTML:

- **Chrome / Brave / Edge**: Abra o Gestor de marcadores (`Ctrl+Shift+O` ou `Cmd+Option+B`) → clique no menu `⋮` → selecione **Exportar marcadores**.
- **Firefox**: Abra a Biblioteca (`Ctrl+Shift+O` ou `Cmd+Shift+O`) → **Importar e salvaguardar** → **Exportar marcadores para HTML…**.
- **Safari**: Ficheiro → **Exportar marcadores…**.

Depois, no Nori, vá a **Definições → Marcadores → Importar marcadores**, selecione o ficheiro `.html` e o Nori importará todas as ligações e pastas para as listas correspondentes.

## Posso fazer cópia de segurança e restaurar os meus marcadores?

Sim. Em **Definições → Marcadores**:

- **Exportar cópia de segurança**: Guarda um ficheiro de cópia de segurança JSON completo contendo todas as listas, marcadores, etiquetas e definições.
- **Restaurar cópia de segurança**: Restaura a partir de um ficheiro de cópia de segurança Nori existente.
- **Exportar HTML / Texto simples**: Cria um ficheiro HTML compatível com navegadores ou uma lista de texto legível.

## Como funciona a sincronização entre vários dispositivos?

O Nori Sync liga as suas aplicações móveis, aplicações para computador e extensões de navegador:

- Os marcadores permanecem em cache localmente em cada dispositivo para funcionalidade offline completa.
- Quando ligado, as alterações sincronizam perfeitamente em todos os clientes ativos.

## A extensão de navegador rastreia a minha atividade de navegação?

Não. O Nori não monitoriza o seu histórico de navegação nem lê o conteúdo das páginas web. A extensão apenas recebe URLs quando abre a janela pop-up e clica para guardar o separador atual.
