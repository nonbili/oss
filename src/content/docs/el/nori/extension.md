Το Nori περιλαμβάνει μια επέκταση προγράμματος περιήγησης τοπικής προτεραιότητας για Mozilla Firefox και Google Chrome.

## Βασικά Χαρακτηριστικά

- **Αντικατοπτρίζει την εμπειρία κινητού**: Το αναδυόμενο παράθυρο της επέκτασης παρέχει τις ίδιες λίστες, συρτάρι αναζήτησης, ιστορικό, διαχείριση λιστών και ρυθμίσεις με την εφαρμογή για κινητά.
- **Προσθήκη σελιδοδείκτη με ένα κλικ**: Αποθηκεύστε άμεσα την τρέχουσα καρτέλα στην επιλεγμένη λίστα σας με αυτόματη ανάκτηση τίτλου.
- **Γρήγορος εκκινητής**: Αναζητήστε και ανοίξτε τους αποθηκευμένους συνδέσμους σας σε νέες καρτέλες απευθείας από τη γραμμή εργαλείων του προγράμματος περιήγησής σας.
- **Τοπική αποθήκευση**: Αποθηκεύει τους σελιδοδείκτες τοπικά στον χώρο αποθήκευσης επεκτάσεων με προαιρετική υποστήριξη Nori Sync.
- **Εστίαση στο απόρρητο**: Καμία δραστηριότητα περιήγησης ή περιεχόμενο σελίδας δεν παρακολουθείται. Το Nori λαμβάνει μόνο τους συνδέσμους που αποθηκεύετε ρητά.

## Εγκατάσταση της Επέκτασης

Εγκαταστήστε το Nori απευθείας από τα επίσημα καταστήματα επεκτάσεων:

- [Firefox Add-ons](https://addons.mozilla.org/addon/nori/)
- [Chrome Web Store](https://chromewebstore.google.com/detail/nori/ojgmnocnegcbhlmfoackgoocnjbfejpg)

## Μεταγλώττιση από τον Πηγαίο Κώδικα

Η επέκταση είναι ανοιχτού κώδικα και έχει δημιουργηθεί με το [WXT](https://wxt.dev/) χρησιμοποιώντας το Manifest V3:

```bash
cd extension
bun install
bun run dev          # Λειτουργία ανάπτυξης Chrome
bun run dev:firefox  # Λειτουργία ανάπτυξης Firefox
bun run build:all    # Δημιουργία τελικών πακέτων zip
```
