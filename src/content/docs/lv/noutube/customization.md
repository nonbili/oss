NouTube atbalsta pielāgotu CSS iegultajām YouTube un YouTube Music lapām.

## Kam noder pielāgots CSS

- Elementu paslēpšanai, kas jums neinteresē
- Lapas blīvuma palielināšanai
- Atstarpju vai tipogrāfijas pielāgošanai
- Vietnes saskarnes izvēļu apiešanai, kas jums traucē

## Ieteicamā pieeja

Saglabājiet izmaiņas šauras un viegli noņemamas.

- Sāciet ar vienu vai divām mērķtiecīgām kārtulām
- Dodiet priekšroku stabiliem selektoriem, kur tas iespējams
- Atkārtoti pārbaudiet pēc sākotnējās vietnes izkārtojuma izmaiņām

Tā kā NouTube ietver tiešsaistes tīmekļa vietnes, pielāgots CSS var pārstāt darboties, kad YouTube maina savu iezīmējumu.

## Pirms pielāgošanas

Pārliecinieties, ka lietotnes noklusējuma darbība jau strādā:

- Atskaņošana
- Navigācija
- Plūsmas
- Lejupielādes

Kad pamats ir stabils, pievienojiet CSS izmaiņas pakāpeniski.
