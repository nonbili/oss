NouTube ondersteunt aangepaste CSS voor de ingesloten pagina's van YouTube en YouTube Music.

## Waar aangepaste CSS goed voor is

- Elementen verbergen die je niet interesseren
- Paginadichtheid compacter maken
- Tussenruimte of typografie aanpassen
- Omgaan met UI-keuzes van de site die je in de weg zitten

## Aanbevolen aanpak

Houd wijzigingen klein en makkelijk te verwijderen.

- Begin met een of twee gerichte regels
- Gebruik waar mogelijk stabiele selectors
- Test opnieuw na wijzigingen in de site-indeling

Omdat NouTube live webpagina's verpakt, kan aangepaste CSS breken wanneer YouTube zijn HTML-structuur wijzigt.

## Voordat je aanpast

Zorg ervoor dat het standaardgedrag van de app al goed werkt voor:

- Afspelen
- Navigatie
- Feeds
- Downloads

Zodra de basis stabiel is, voeg je geleidelijk CSS-wijzigingen toe.
