O NouTube suporta CSS personalizado para as páginas incorporadas do YouTube e YouTube Music.

## Para que serve o CSS personalizado

- Ocultar elementos que não lhe interessam
- Tornar a disposição da página mais compacta
- Ajustar o espaçamento ou a tipografia
- Contornar escolhas de interface do site que atrapalham a utilização

## Abordagem recomendada

Mantenha as alterações limitadas e fáceis de remover.

- Comece com uma ou duas regras direcionadas
- Prefira seletores estáveis sempre que possível
- Volte a testar após alterações na disposição do site original

Como o NouTube envolve propriedades web em direto, o CSS personalizado pode deixar de funcionar quando o YouTube altera a sua marcação.

## Antes de personalizar

Certifique-se de que o comportamento predefinido da aplicação já funciona para:

- Reprodução
- Navegação
- Feeds
- Transferências

Assim que a base estiver estável, adicione alterações de CSS gradualmente.
