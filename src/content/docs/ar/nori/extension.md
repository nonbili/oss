يتضمن Nori امتداد متصفح محلي أولاً لمتصفحي Mozilla Firefox و Google Chrome.

## الميزات الرئيسية

- **تجربة مطابقة لتطبيق الهاتف**: توفر نافذة الامتداد المنبثقة نفس القوائم، ودرج البحث، والسجل، وإدارة القوائم، والإعدادات كما في تطبيق الهاتف.
- **حفظ الإشارات بنقرة واحدة**: حفظ علامة التبويب النشطة فورًا في قائمتك المختارة مع جلب العنوان تلقائيًا.
- **مشغل سريع**: ابحث عن روابطك المحفوظة وافتحها في علامات تبويب جديدة مباشرة من شريط أدوات المتصفح.
- **تخزين محلي**: حفظ الإشارات المرجعية محليًا في وحدة تخزين الامتداد بالمتصفح مع دعم اختياري لمزامنة Nori Sync.
- **التركيز على الخصوصية**: لا يتم تتبع نشاط التصفح أو قراءة محتويات الصفحات؛ يتلقى Nori فقط الروابط التي تحفظها صراحة.

## تثبيت الامتداد

قم بتثبيت Nori مباشرة من متاجر الامتدادات الرسمية:

- [Firefox Add-ons](https://addons.mozilla.org/addon/nori/)
- [Chrome Web Store](https://chromewebstore.google.com/detail/nori/ojgmnocnegcbhlmfoackgoocnjbfejpg)

## البناء من الكود المصدري

الامتداد مفتوح المصدر ومبني باستخدام [WXT](https://wxt.dev/) ومعيار Manifest V3:

```bash
cd extension
bun install
bun run dev          # وضع التطوير لمتصفح Chrome
bun run dev:firefox  # وضع التطوير لمتصفح Firefox
bun run build:all    # بناء حزم zip النهائية للإنتاج
```
