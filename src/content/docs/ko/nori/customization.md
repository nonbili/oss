Nori는 개인의 작업 흐름에 맞춰 런처를 꾸밀 수 있도록 포괄적인 모양 및 레이아웃 옵션을 제공합니다.

## 테마

**Settings → Appearance → Theme**에서 네 가지 화면 모드를 전환할 수 있습니다:

- **System**: 운영체제의 라이트/다크 모드 설정에 자동으로 맞춥니다.
- **Light**: 텍스트와 아이콘 대비가 높은 선명한 밝은 화면입니다.
- **Dark**: 어두운 환경에서 눈의 피로를 줄이도록 설계된 짙은 회색 톤입니다.
- **AMOLED**: OLED 디스플레이에서 배터리 절약을 극대화하는 순수 검정(`#000000`) 배경입니다.

## 강조 색상 및 Material You

Nori 전반에 사용되는 기본 강조 색상을 개인화하세요:

- **System Color (Dynamic Wallpaper)**: Android에서 Nori는 기기 배경화면에서 색조를 직접 추출하는 Material You 동적 테마를 지원합니다.
- **Custom Color Picker**: 원하는 색조를 고르거나, 강도를 조절하거나, 정확한 16진수 코드를 입력하세요. Nori가 라이트 및 다크 배경 모두에 어울리는 접근성 높은 보색 틴트를 자동으로 계산합니다.

## 타이포그래피

**Settings → Appearance → Font**에서 읽기 편한 글꼴을 미세 조정하세요:

- **Font Family**: **Default**(시스템 산세리프), **Serif**(클래식 편집 서체), **Monospace**(코드 스타일) 중에서 전환합니다.
- **Font Size**: 실시간 미리보기를 보며 텍스트 크기를 키우거나 줄입니다.

## 레이아웃 및 표시 옵션

- **Columns**: 간결한 1열 목록과 더 넓은 2열 그리드 중에서 선택합니다.
- **Bookmark View**: **Compact**(빠른 실행 알약형 버튼)와 **Preview**(커버 이미지와 설명이 포함된 리치 카드) 사이를 전환합니다.
- **Site Favicons**: 도메인을 빠르게 구분하려면 실시간 사이트 파비콘을 켜고, 깔끔한 단색 Nori 아이콘을 보려면 끄세요.
