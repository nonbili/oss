## Nach der Installation

- **Mobil**: Teilen Sie einen Link aus Ihrem Webbrowser mit Nori über das Freigabemenü des Systems, um die Link-Verarbeitung zu überprüfen.
- **Desktop**: Stellen Sie unter Linux (AppImage) sicher, dass GTK 3 und `webkit2gtk-4.1` installiert sind (`libwebkit2gtk-4.1-0` auf Debian/Ubuntu, `webkit2gtk4.1` auf Fedora, `webkit2gtk-4.1` auf Arch).
- **Erweiterung**: Heften Sie die Nori-Erweiterung an Ihre Browser-Symbolleiste an, um mit einem Klick Lesezeichen zu setzen und zu suchen.
- Fahren Sie mit der [Übersicht](/de/nori/) für den Produktkontext fort oder mit den [Funktionen](/de/nori/features/) für die vollständige Liste der Möglichkeiten.
