В **Nora 0.9.7 для мобильных устройств** вы можете отправлять загрузки Android в выбранную папку и сократить меню браузера с тремя точками до тех действий, которыми пользуетесь. Также этот выпуск автоматически открывает WhatsApp Web и Facebook Marketplace в режиме для ПК.

## Выберите, куда сохранять загрузки

На Android откройте **Настройки → Предпочтения → Загрузки → Сохранять загрузки в**, чтобы указать папку для загрузок браузера.

- **Загрузки** использует стандартную папку Downloads в Android.
- **Спрашивать каждый раз** позволяет выбирать место назначения для каждой загрузки.
- **Выбрать папку…** сохраняет будущие загрузки в указанную вами папку.

Если вы выберете папку, Nora также будет использовать её для медиафайлов, сохраняемых из ленты на Android 10 и новее. Кроме того, в этом выпуске исправлена загрузка по ссылкам `data:`, которые некоторые сайты используют для файлов, создаваемых прямо в браузере.

## Настройте меню с тремя точками

Откройте **Настройки → Внешний вид → Панель инструментов → Настроить меню с тремя точками** и отключите редко используемые действия. Например, оставьте **Найти на странице** и **Поделиться**, а **Версию для ПК** скройте, если редко переключаете макет. Оставленные действия появляются, когда они доступны на текущей вкладке.

Пункт **Настройки** остаётся в меню, а **Сбросить меню по умолчанию** отменяет ваши изменения одним нажатием.

## WhatsApp Web и Facebook Marketplace открываются в режиме для ПК

В **WhatsApp Web** экранная клавиатура теперь может открываться, не закрывая окно выбора. **Facebook Marketplace** использует версию сайта для ПК, чтобы вы могли писать продавцам прямо со страницы объявления.

## Исправления браузера и ленты

- Блокировка рекламы в Facebook теперь распознаёт рекламные публикации, даже если их пометки появляются с задержкой. При долгом нажатии на кнопку реакции в Facebook контекстное меню браузера больше не мешает.
- Фильтр игр Reddit оставляет обычные публикации видимыми.
- Переключатель вкладок открывается так, что активная вкладка сразу видна. На новой вкладке введённый адрес открывается с первого нажатия **Перейти**, а открытие входящей ссылки сохраняет остальные вкладки.
- Жест «потянуть для обновления» больше не срабатывает, когда вы делаете жесты внутри просмотрщика медиафайлов.

Полный список изменений смотрите в [примечаниях к выпуску на GitHub](https://github.com/nonbili/Nora/releases/tag/v0.9.7).
