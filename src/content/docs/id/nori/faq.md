## Bagaimana cara menyimpan tautan ke Nori dari browser seluler?

Gunakan menu berbagi sistem standar:

1. Di browser Anda (Chrome, Firefox, Safari, Brave, dll.), ketuk **Bagikan**.
2. Pilih **Nori** dari daftar aplikasi.
3. Pilih daftar tujuan tempat Anda ingin menyimpan tautan, atau aktifkan **Simpan cepat tautan bersama** di pengaturan untuk langsung menyimpan tanpa dialog konfirmasi.

## Bisakah saya membuka markah langsung di aplikasi browser daripada tab dalam aplikasi?

Bisa. Buka **Pengaturan → Umum** dan aktifkan **Buka tautan di browser bawaan**. Saat aktif, mengetuk markah apa pun akan langsung meneruskan URL ke aplikasi browser default ponsel Anda.

## Bagaimana cara mengimpor markah dari browser desktop?

Ekspor markah yang ada ke file HTML:

- **Chrome / Brave / Edge**: Buka Pengelola Markah (`Ctrl+Shift+O` atau `Cmd+Option+B`) → klik menu `⋮` → pilih **Ekspor markah**.
- **Firefox**: Buka Perpustakaan/Bookmark (`Ctrl+Shift+O` atau `Cmd+Shift+O`) → **Impor dan Cadangkan** → **Ekspor Markah ke HTML…**.
- **Safari**: File → **Ekspor Markah…**.

Kemudian di Nori, buka **Pengaturan → Markah → Impor markah**, pilih file `.html` tersebut, dan Nori akan mengimpor semua tautan dan folder ke daftar yang sesuai.

## Bisakah saya mencadangkan dan memulihkan markah saya?

Bisa. Di **Pengaturan → Markah**:

- **Ekspor cadangan**: Menyimpan file cadangan JSON lengkap yang berisi semua daftar, markah, tag, dan pengaturan.
- **Pulihkan cadangan**: Memulihkan dari file cadangan Nori yang sudah ada.
- **Ekspor HTML / Teks biasa**: Membuat file HTML yang kompatibel dengan browser atau daftar teks yang mudah dibaca.

## Bagaimana cara kerja sinkronisasi multiperangkat?

Nori Sync menghubungkan aplikasi seluler, aplikasi desktop, dan ekstensi browser Anda:

- Markah tetap tersimpan secara lokal di setiap perangkat untuk fungsi offline penuh.
- Saat terhubung, perubahan disinkronkan secara mulus di semua klien yang aktif.

## Apakah ekstensi browser melacak aktivitas penjelajahan saya?

Tidak. Nori tidak memantau riwayat penjelajahan Anda atau membaca konten halaman web. Ekstensi hanya menerima URL ketika Anda membuka popup dan mengklik untuk menyimpan tab saat ini.
