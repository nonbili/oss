モバイル版 **Nora 0.9.5** では、モバイルでのプロキシのユーザー名とパスワードの入力に対応し、X の表示内容をさらに細かく制御できるようになりました。また、Facebook の広告フィルタリングとブラウザ Cookie のインポートも改善されています。

## モバイルでプロキシにログイン

**設定 → ブラウジング → プロキシ** を開いて HTTP または SOCKS を選択し、ホストとポートを入力した上で、ユーザー名とパスワードを設定できます。認証付きプロキシは **Android** および **iOS 17 以降** でサポートされており、Web ブラウジングとフィード取得の両方で利用可能です。

認証情報は端末内に保持され、バックアップや同期の対象からは除外されます。iOS 16 では、引き続きフィード用の認証なし HTTP プロキシのみの対応となります。

## X で非表示にする要素を選択

**設定 → サービス → X** で、以下の項目を個別に非表示にできるようになりました：

- **Grok UI**: Grok のインターフェース要素を非表示にします。
- **おすすめ**: おすすめユーザー、トレンド、その他のコンテンツなどの推薦表示を削除します。
- **エンゲージメント数**: 数字に気を取られずに閲覧できるよう、タイムライン上の数値を非表示にします。

これらのコントロールは任意で設定できます。同じ設定画面で **検索時に「最新」をデフォルトにする** を有効にすれば、「話題のツイート」ではなく最新の投稿が最初に表示されます。別のタブで検索結果を見たい場合は、X 上でいつでもタブを切り替えられます。

## Facebook の通常投稿を確実に表示

Facebook の広告フィルタリングでスポンサーラベル自体を直接確認するようになりました。「広告」や「Ad」という単語が含まれているだけの通常の投稿が誤って非表示になる可能性が低減しました。

## より確実な Cookie インポート

ブラウザ Cookie のインポート時に、`__Host-` や `__Secure-` で始まるプレフィックス付きの Cookie 名が正しく維持されるようになりました。これらのプレフィックスを損なわずに取り込むことで、各 Web サイトでインポートしたセッションが正しく認識されます。
