*Δημοσιεύτηκε στις 22 Οκτωβρίου 2026*

Το **Nora 0.9.0** προσθέτει ένα ενσωματωμένο πρόγραμμα ανάγνωσης ροών σε Android, iOS και desktop. Ακολουθήστε λογαριασμούς σε X, Instagram, Bluesky, Mastodon και άλλα υποστηριζόμενα δίκτυα και οργανώστε τις αναρτήσεις τους στα δικά σας χρονολογικά χρονολόγια. Πολλές πηγές λειτουργούν χωρίς να απαιτείται σύνδεση.

Περιηγηθείτε σε όλα μαζί, διαχωρίστε τα ενδιαφέροντά σας σε διαφορετικά χρονολόγια ή μεταβείτε σε ένα πλέγμα φωτογραφιών και βίντεο.

## Ακολουθήστε λογαριασμούς σε διάφορα κοινωνικά δίκτυα

Ανοίξτε ένα υποστηριζόμενο προφίλ ή κοινότητα σε μια καρτέλα του Nora και επιλέξτε **Παρακολούθηση** από το μενού. Οι πιο πρόσφατες αναρτήσεις του θα εμφανιστούν στο **Feed** του Nora. Πατήστε σε μια ανάρτηση για να ανοίξετε την αρχική σελίδα όποτε θέλετε να διαβάσετε απαντήσεις ή να αλληλεπιδράσετε.

Μπορείτε να ακολουθήσετε:

- Προφίλ **X (Twitter)**, **Instagram**, **Threads**, **Bluesky** και **TikTok**
- Προφίλ **Mastodon** σε όλους τους διακομιστές
- Subreddit και προφίλ χρηστών **Reddit**
- Σελίδες, προφίλ και ομάδες **Facebook**

Για να προσθέσετε πολλές πηγές ταυτόχρονα, επικολλήστε μια λίστα συνδέσμων προφίλ ή εισαγάγετε ένα αρχείο OPML. Οι φάκελοι OPML γίνονται χρονολόγια, ώστε να διατηρήσετε την υπάρχουσα οργάνωσή σας. Η οθόνη **Διαχείριση πηγών** σάς επιτρέπει να αναζητάτε, να φιλτράρετε και να ταξινομείτε τους λογαριασμούς που ακολουθείτε, καθώς και να τους εξαγάγετε ξανά.

## Οργανώστε τα δικά σας χρονολόγια

Κρατήστε φίλους, ειδήσεις και χόμπι σε ξεχωριστά **προσαρμοσμένα χρονολόγια**, το καθένα με το δικό του εικονίδιο emoji και καρτέλα ροής. Καρφιτσώστε ένα χρονολόγιο στη σελίδα Νέα καρτέλα για γρήγορη πρόσβαση ή διατηρήστε όλες τις πηγές σας μαζί σε μία μόνο ροή.

Μέσα σε ένα χρονολόγιο, πατήστε το avatar ή το όνομα ενός συντάκτη για να εστιάσετε στις αναρτήσεις του. Μπορείτε επίσης να επιλέξετε μια πηγή από τον επιλογέα στο επάνω μέρος της ροής.

Επιλέξτε πόσο συχνά το Nora ελέγχει για ενημερώσεις και ποιες αναρτήσεις ενεργοποιούν ειδοποιήσεις. Ορίστε προεπιλογές για όλες τις πηγές, προσαρμόστε τις για ένα συγκεκριμένο χρονολόγιο ή κάντε σίγαση μιας μεμονωμένης πηγής. Εάν ένα δίκτυο απαιτεί σύνδεση, μπορείτε να επιλέξετε ποιο προφίλ Nora θα χρησιμοποιηθεί ή να απενεργοποιήσετε τους ελέγχους συνδεδεμένων λογαριασμών.

Οι πηγές και τα χρονολόγια που παρακολουθείτε περιλαμβάνονται στα αντίγραφα ασφαλείας των ρυθμίσεων και στον προαιρετικό συγχρονισμό στο cloud, ώστε να τα διατηρείτε σε όλες τις συσκευές σας.

## Περιηγηθείτε σε φωτογραφίες και βίντεο

Μεταβείτε σε ένα χρονολόγιο στη λειτουργία **Μόνο φωτογραφίες και βίντεο** για να δείτε τα πολυμέσα του σε πλέγμα. Ανοίξτε μια εικόνα ή ένα βίντεο για να περιηγηθείτε στην γκαλερί, να μεγεθύνετε φωτογραφίες, να αναπαραγάγετε βίντεο ή να πραγματοποιήσετε λήψη πολυμέσων στη συσκευή σας.

Το Nora αποθηκεύει προσωρινά τις αναρτήσεις ροής και τα πολυμέσα τοπικά. Μπορείτε να περιορίσετε τον χώρο αποθήκευσης πολυμέσων, να εκκαθαρίσετε την προσωρινή μνήμη και να περιορίσετε την προφόρτωση πολυμέσων μόνο σε Wi-Fi.

## Άλλες βελτιώσεις

Αυτή η έκδοση προσθέτει επίσης:

- **Αναδιάταξη καρτελών:** Πατήστε παρατεταμένα και σύρετε καρτέλες στον επιλογέα καρτελών σε κινητά.
- **Εύρεση στη σελίδα:** Αναζητήστε σε μια ανοιχτή ιστοσελίδα με ζωντανό αριθμό αποτελεσμάτων και στοιχεία ελέγχου επόμενου/προηγούμενου.
- **Σύνδεσμοι με επίγνωση προφίλ:** Οι σύνδεσμοι παραμένουν στο προφίλ της αρχικής καρτέλας και μπορείτε να πατήσετε παρατεταμένα μια καρτέλα για να την ανοίξετε ξανά σε άλλο προφίλ.
- **Βελτιώσεις συγχρονισμού:** Οι αλλαγές σε ρυθμίσεις, σελιδοδείκτες και στυλ χρήστη συγχωνεύονται μεταξύ συσκευών, με τοπικά αντίγραφα ασφαλείας διαθέσιμα για επαναφορά.

Ανατρέξτε στο [αρχείο καταγραφής αλλαγών](/el/nora/changelog/) για όλες τις λεπτομέρειες της έκδοσης.
