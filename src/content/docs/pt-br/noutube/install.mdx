## Após a instalação

- **Mobile**: Abra um link do YouTube ou do YouTube Music no NouTube se o seu dispositivo perguntar qual aplicativo usar. No iOS, participe da versão beta pelo TestFlight.
- **Desktop**: Confirme se a reprodução funciona como esperado antes de alterar configurações avançadas.
- **Extensão**: Fixe a extensão do NouTube na barra de ferramentas do seu navegador ou veja [Extensão de navegador](/pt-br/noutube/extension/) para mais detalhes.
- Continue com [Visão geral](/pt-br/noutube/) para o contexto do produto ou [Recursos](/pt-br/noutube/features/) para a lista completa de funcionalidades.
