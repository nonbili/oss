O Nora suporta CSS personalizado para que possa remodelar os sites dos serviços que incorpora.

## Utilizações comuns

- Ocultar elementos de interface que distraem
- Melhorar a densidade para disposições com muitas linhas cronológicas
- Remover elementos específicos do serviço que nunca utiliza
- Tornar as configurações de várias colunas no computador mais fáceis de percorrer

## Manter as alterações sustentáveis

Como o Nora depende dos sites em direto de serviços externos, a marcação original pode mudar sem aviso prévio.

Utilize uma abordagem conservadora:

- Prefira regras pequenas e direcionadas
- Volte a testar após reformulações do serviço
- Evite substituições amplas, a menos que controle os efeitos secundários

## Associar CSS a perfis

Se utilizar perfis separados para diferentes serviços ou funções, mantenha os ajustes de CSS alinhados com esses perfis para que o comportamento se mantenha previsível.
