## Efter Installation

- **Mobil**: Öppna en YouTube- eller YouTube Music-länk i NouTube om din enhet frågar vilken app som ska användas. På iOS, gå med i betan via TestFlight.
- **Desktop**: Bekräfta att uppspelningen fungerar som du förväntar dig innan du ändrar avancerade inställningar.
- **Tillägg**: Fäst NouTube-tillägget i webbläsarens verktygsfält, eller se [Webbläsartillägg](/sv/noutube/extension/) för mer information.
- Fortsätt med [Översikt](/sv/noutube/) för produktkontext, eller [Funktioner](/sv/noutube/features/) för den fullständiga listan över funktioner.
