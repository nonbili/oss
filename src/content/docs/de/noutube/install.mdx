## Nach der Installation

- **Mobil**: Öffnen Sie einen YouTube- oder YouTube-Music-Link in NouTube, wenn Ihr Gerät fragt, welche App verwendet werden soll. Treten Sie unter iOS der Beta über TestFlight bei.
- **Desktop**: Vergewissern Sie sich, dass die Wiedergabe wie erwartet funktioniert, bevor Sie erweiterte Einstellungen ändern.
- **Erweiterung**: Heften Sie die NouTube-Erweiterung an Ihre Browser-Symbolleiste an oder lesen Sie [Browser-Erweiterung](/de/noutube/extension/) für Details.
- Weitere Produktdetails finden Sie in der [Übersicht](/de/noutube/) und in den [Funktionen](/de/noutube/features/).
