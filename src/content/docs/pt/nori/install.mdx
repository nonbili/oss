## Após a instalação

- **Telemóvel**: Experimente partilhar uma ligação do seu navegador web para o Nori utilizando o menu de partilha do sistema para verificar o tratamento de ligações.
- **Computador**: No Linux AppImage, certifique-se de que o GTK 3 e o `webkit2gtk-4.1` estão instalados (`libwebkit2gtk-4.1-0` no Debian/Ubuntu, `webkit2gtk4.1` no Fedora, `webkit2gtk-4.1` no Arch).
- **Extensão**: Afixe a extensão Nori na barra de ferramentas do seu navegador para marcar e pesquisar rapidamente com um clique.
- Continue com [Visão geral](/pt/nori/) para o contexto do produto, ou [Funcionalidades](/pt/nori/features/) para a lista completa de capacidades.
