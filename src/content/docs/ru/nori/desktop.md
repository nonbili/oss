Nori предоставляет отдельное нативное приложение для Linux, macOS и Windows.

## Преимущества десктопной версии

Десктопная версия переносит удобный лаунчер закладок Nori на ваш компьютер как быстрое приложение с поддержкой горячих клавиш:

- **Автономный лаунчер**: Организуйте ссылки в отдельном окне, не перегружая панель вкладок браузера.
- **Локальная архитектура**: Приложение создано на базе [Wails v3](https://v3.wails.io/) и Go, сочетая нативные окна операционной системы с современным веб-интерфейсом.
- **Запуск в системном браузере**: При нажатии на ссылку она сразу открывается в вашем браузере по умолчанию.
- **Интеграция с синхронизацией**: Подключите учетную запись Nori Sync для бесшовной синхронизации закладок между компьютером, смартфоном и браузерным расширением.

## Пакеты для платформ

- **Linux**: Распространяется в виде переносимых пакетов AppImage и `.tar.gz` для архитектуры `amd64`.
- **macOS**: Универсальная поддержка Apple Silicon (`arm64`) и Intel (`amd64`), доступная в виде образов `.dmg` и архивов `.app.zip`.
- **Windows**: Распространяется в виде установочных файлов `.exe` и переносимых архивов `.zip`.

## Системные требования для Linux

AppImage для Linux использует системный движок WebKit. Убедитесь, что в вашей системе установлены GTK 3 и `webkit2gtk-4.1`:

- **Debian / Ubuntu**:
  ```bash
  sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0 libfuse2
  ```
- **Fedora**:
  ```bash
  sudo dnf install webkit2gtk4.1 gtk3
  ```
- **Arch Linux**:
  ```bash
  sudo pacman -S webkit2gtk-4.1 gtk3
  ```
