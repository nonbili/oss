## Après l'installation

- **Mobile** : Partagez un lien depuis votre navigateur web vers Nori via le menu de partage pour vérifier la prise en charge des liens.
- **Bureau** : Sur Linux (AppImage), assurez-vous que GTK 3 et `webkit2gtk-4.1` sont installés (`libwebkit2gtk-4.1-0` sur Debian/Ubuntu, `webkit2gtk4.1` sur Fedora, `webkit2gtk-4.1` sur Arch).
- **Extension** : Épinglez l'extension Nori à la barre d'outils de votre navigateur pour enregistrer et rechercher des favoris en un clic.
- Poursuivez avec la [Présentation](/fr/nori/) pour le contexte général ou les [Fonctionnalités](/fr/nori/features/) pour la liste complète des capacités.
