## Come posso salvare i link in Nori dal browser del telefono?

Usa il menu di condivisione standard del sistema:

1. Nel tuo browser (Chrome, Firefox, Safari, Brave, ecc.), tocca **Condividi**.
2. Seleziona **Nori** dall'elenco delle app.
3. Scegli la lista di destinazione in cui desideri salvare il link, oppure attiva **Salvataggio rapido dei link condivisi** nelle impostazioni per salvare direttamente in una lista prestabilita senza richieste.

## Posso aprire i segnalibri direttamente nell'app del mio browser invece che in una scheda interna?

Sì. Vai su **Impostazioni → Generale** e attiva **Apri i link nel browser predefinito**. Quando l'opzione è abilitata, toccando un segnalibro l'URL verrà immediatamente aperto nell'app del browser predefinito del telefono.

## Come posso importare i miei segnalibri dai browser desktop?

Esporta i segnalibri esistenti in un file HTML:

- **Chrome / Brave / Edge**: Apri Gestione Preferiti (`Ctrl+Maiusc+O` o `Cmd+Opzione+B`) → fai clic sul menu `⋮` → seleziona **Esporta preferiti**.
- **Firefox**: Apri la Libreria (`Ctrl+Maiusc+O` o `Cmd+Maiusc+O`) → **Importa e salva** → **Esporta segnalibri in HTML…**.
- **Safari**: File → **Esporta segnalibri…**.

Quindi in Nori, vai su **Impostazioni → Segnalibri → Importa segnalibri**, seleziona il file `.html` e Nori importerà tutti i link e le cartelle nelle liste corrispondenti.

## Posso eseguire il backup e il ripristino dei miei segnalibri?

Sì. In **Impostazioni → Segnalibri**:

- **Esporta backup**: Salva un file di backup JSON completo contenente tutte le liste, i segnalibri, i tag e le impostazioni.
- **Ripristina**: Ripristina i dati da un file di backup di Nori precedentemente salvato.
- **Esporta HTML / Esporta testo semplice**: Crea un file HTML compatibile con i browser o un elenco di testo leggibile.

## Come funziona la sincronizzazione tra dispositivi?

Nori Sync collega le tue app mobili, app desktop ed estensioni del browser:

- I segnalibri restano salvati in locale su ciascun dispositivo per garantire la piena operatività offline.
- Quando sei connesso, le modifiche si sincronizzano senza interruzioni su tutti i dispositivi attivi.

## L'estensione per browser traccia la mia attività di navigazione?

No. Nori non monitora la cronologia né legge il contenuto delle pagine web. L'estensione riceve gli URL solo quando apri la finestra popup e confermi di voler salvare la scheda aperta.
