## Organizzazione delle liste

- **Liste multiple**: Suddividi i tuoi link in categorie mirate come Social network, Lavoro, Lettura, Notizie o Strumenti IA.
- **Gestione delle liste**: Crea, rinomina, nascondi o elimina le liste in base all'evoluzione del tuo flusso di lavoro.
- **Riordino tramite trascinamento**: Disponi liste e segnalibri esattamente nell'ordine preferito.
- **Spostamento ed eliminazione di gruppo**: Seleziona più segnalibri per spostarli tra le liste o ripulire gli elementi obsoleti.

## Apertura e navigazione

- **Passaggio al browser predefinito**: Apri i segnalibri direttamente nell'app browser preferita del tuo sistema.
- **Schede integrate (Custom Tabs)**: Su Android e iOS, usa opzionalmente le Custom Tabs integrate o Safari View Controller per una rapida consultazione senza cambiare applicazione.
- **Risoluzione favicon**: Scarica automaticamente le favicon dei domini, con l'opzione di visualizzare invece il logo minimale di Nori.

## Integrazione con il menu di condivisione

- **Ricezione da condivisione di sistema**: Invia link a Nori direttamente dal menu di condivisione di qualsiasi browser web, app di messaggistica o lettore.
- **Selezione della lista di destinazione**: Scegli la lista desiderata non appena salvi il link.
- **Salvataggio rapido**: Imposta una lista predefinita per salvare i link condivisi all'istante senza richieste di conferma.
- **Titoli automatici delle pagine**: Recupera automaticamente il titolo della pagina web quando aggiungi un link.

## Modalità di visualizzazione

- **Avviatore compatto**: Pulsanti essenziali ottimizzati per un'apertura con un solo tocco e un'elevata densità di informazioni.
- **Schede di anteprima**: Schede visive arricchite con immagini di copertina dei siti web ed estratti di testo descrittivi.
- **Densità del layout**: Scegli tra una disposizione a 1 colonna o a 2 colonne in base alle dimensioni dello schermo e alle preferenze di lettura.

## Pannello di ricerca e cronologia

- **Ricerca rapida**: Filtra tutti i segnalibri per titolo, URL o tag personalizzati in tempo reale.
- **Opzioni di ordinamento**: Ordina i segnalibri per più recenti, meno recenti, per nome (A–Z) o in ordine alfabetico inverso (Z–A).
- **Usati di recente**: Riapri i link consultati di recente senza doverli cercare nelle liste.
- **Aggiunti di recente**: Visualizza gli ultimi segnalibri aggiunti a colpo d'occhio.

## Importazione, esportazione e backup

- **Importazione HTML dai browser**: Importa file standard di segnalibri HTML esportati da Chrome, Firefox, Safari, Edge o Brave.
- **Esportazione in testo semplice**: Esporta elenchi leggibili di titoli e URL per appunti e documentazione.
- **Backup e ripristino completi**: Salva un backup JSON portabile di tutta la tua configurazione, liste e segnalibri per preservare i dati.

## Sincronizzazione cloud

- **Sincronizzazione multidispositivo**: Sincronizzazione cloud opzionale tramite Nori Sync per mantenere aggiornati liste e segnalibri su smartphone, tablet, computer ed estensione browser.
- **Approccio locale (Local-First)**: Tutti i segnalibri rimangono memorizzati localmente sul dispositivo, garantendo la disponibilità completa offline anche senza connessione internet attiva.
