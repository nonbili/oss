NouTube — це програма для Android та комп'ютерів для роботи з YouTube та YouTube Music.

Вона обгортає мобільні вебпрограми YouTube та YouTube Music і додає поверх них нативні можливості, зокрема блокування реклами, перехоплення керування відтворенням, підтримку завантажень, RSS-стрічки та керування бібліотекою в офлайн-режимі.

## Основне

- Без реклами
- Фонове відтворення
- Підтримка відео та музики в одній програмі
- Керування бібліотекою та історією без входу в акаунт
- Завантаження відео
- Читач RSS-стрічок для каналів YouTube
- Підтримка живого чату
- Підтримка власного CSS

## Платформи

- Android
- Комп'ютери

Збірка для комп'ютерів дотримується тієї самої моделі продукту, що й мобільна програма, із нативними інсталяторами для великих екранів.

## Перший запуск

Після встановлення практичне початкове налаштування виглядає так:

1. Відкрийте YouTube або YouTube Music усередині програми.
2. Перевірте роботу відтворення, особливо фонового, якщо це ваш основний сценарій.
3. Налаштуйте параметри бібліотеки, історії, стрічок та завантажень.
4. Додавайте власний CSS лише після того, як переконаєтеся, що стандартний вигляд працює для вас належним чином.

## Підтримувані посилання

NouTube налаштована на обробку таких хостів:

- `youtube.com`
- `www.youtube.com`
- `m.youtube.com`
- `music.youtube.com`
- `youtu.be`

Якщо пристрій запитає, якою програмою відкрити підтримуване посилання, виберіть `NouTube`.

## Як це працює

NouTube обгортає вебпрограми, а не переписує YouTube з нуля. На практиці це означає:

- Ви зберігаєте звичний інтерфейс і макет офіційного сайту
- Програма додає блокування реклами та нативні елементи керування відтворенням
- Фонове відтворення та інтеграція з пристроєм працюють краще, ніж у звичайному браузері
