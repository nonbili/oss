Nori は、モバイル端末、デスクトップ PC、Web ブラウザの間で日常的に素早くアクセスできるように設計された、オープンソースのブックマークマネージャー兼ランチャーです。

ブラウザの階層深いフォルダツリーや囲い込みの中にリンクを埋もれさせることなく、整理された見やすいリストで管理し、即座の起動、検索、リッチなプレビューカード、共有シート連携を提供します。

## 主な特徴

- 複数のカスタムブックマークリスト
- システムのデフォルトブラウザやネイティブ Custom Tabs での即座の起動
- リスト選択やクイック保存に対応し、あらゆるアプリから共有されたリンクを保存
- 1 タップで開けるコンパクトモードと、Web サイトのカバー画像を表示するプレビューカードモード
- キーワードやタグでリアルタイムに絞り込める検索ドロワー
- 最近開いたリンクや最近追加したリンクの履歴
- 標準 HTML ブックマーク、プレーンテキスト、完全な JSON バックアップのインポート／エクスポート
- 柔軟な外観カスタマイズ: ライト、ダーク、AMOLED、カスタムアクセントカラー
- Chrome および Firefox 向けのローカルファーストなブラウザ拡張機能
- Linux、macOS、Windows 向けのクロスプラットフォームデスクトップアプリ
- Nori Sync による端末間でのオプションのクラウド同期

## プラットフォーム

- **Android**: Google Play および GitHub リリースの APK で提供。
- **iOS**: iPhone および iPad 向けに App Store で提供。
- **デスクトップ**: Linux（AppImage および tarball）、macOS（Apple Silicon および Intel）、Windows 向けのネイティブスタンドアロンアプリ。
- **ブラウザ拡張機能**: Mozilla Firefox および Google Chrome 向けの Manifest V3 拡張機能。

## 最初にやること

おすすめの初期セットアップ手順:

1. よく使うカテゴリ（例: `Daily`、`Tools`、`Reading`、`Work`）のリストをいくつか作成する。
2. よく開くリンクを追加するか、ブラウザからエクスポートした HTML ブックマークをインポートする。
3. ブックマークをタップして起動し、デフォルトブラウザで期待通りに開くか確認する。
4. モバイルブラウザの共有メニューから Web ページを Nori に共有してみる。
5. ダークモードや好みのアクセントカラーなど、外観設定をカスタマイズする。

## 仕組み

Nori は、ブックマークの管理を特定のブラウザエンジンから切り離しています:

- Android では、`expo-web-browser` による Custom Tabs で開くか、システムのデフォルトブラウザアプリに直接引き渡します。
- iOS では、ネイティブの Safari View Controller シートまたはシステムのデフォルトブラウザで開きます。
- デスクトップや拡張機能では、アクティブなブラウザタブで直接リンクを開きます。

この設計により、お好みの広告ブロッカー、ログイン状態、ブラウザプロファイルをそのまま活用しながら、すべてのリンクを高速で検索しやすい 1 つのランチャーに整理できます。
