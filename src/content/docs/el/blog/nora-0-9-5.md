*Δημοσιεύτηκε στις 6 Νοεμβρίου 2026*

Το **Nora 0.9.5 για κινητά** προσθέτει πεδία ονόματος χρήστη και κωδικού πρόσβασης διακομιστή μεσολάβησης (proxy) σε κινητά, καθώς και περισσότερο έλεγχο στο τι εμφανίζεται στο X. Βελτιώνει επίσης το φιλτράρισμα διαφημίσεων στο Facebook και την εισαγωγή cookie του προγράμματος περιήγησης.

## Συνδεθείτε στον διακομιστή μεσολάβησης από κινητό

Ανοίξτε τις **Ρυθμίσεις → Περιήγηση → Διακομιστής μεσολάβησης** για να επιλέξετε HTTP ή SOCKS, εισαγάγετε τον κεντρικό υπολογιστή και τη θύρα και συμπληρώστε το όνομα χρήστη και τον κωδικό πρόσβασής σας. Οι διακομιστές μεσολάβησης με έλεγχο ταυτότητας υποστηρίζονται σε **Android** και **iOS 17 ή νεότερο**, τόσο για την περιήγηση όσο και για τα αιτήματα των ροών.

Τα διαπιστευτήρια παραμένουν τοπικά στη συσκευή και εξαιρούνται από αντίγραφα ασφαλείας και συγχρονισμό. Στο iOS 16, η υποστήριξη διακομιστή μεσολάβησης παραμένει περιορισμένη σε αιτήματα ροής HTTP χωρίς έλεγχο ταυτότητας.

## Επιλέξτε τι θα αποκρύψετε στο X

Στην ενότητα **Ρυθμίσεις → Υπηρεσίες → X**, μπορείτε τώρα να επιλέξετε να αποκρύψετε:

- **Διεπαφή Grok**, για κατάργηση των στοιχείων διεπαφής του Grok.
- **Προτάσεις**, συμπεριλαμβανομένων των «Ποιους να ακολουθήσετε», τάσεων και «Ανακαλύψτε περισσότερα».
- **Μετρητές αλληλεπίδρασης**, για ένα χρονολόγιο με λιγότερους αριθμούς που αποσπούν την προσοχή.

Αυτά τα στοιχεία ελέγχου είναι προαιρετικά. Η ίδια ενότητα ρυθμίσεων προσφέρει επίσης την επιλογή **Προεπιλογή αναζήτησης στα Πρόσφατα**, ώστε οι αναζητήσεις να ξεκινούν με πρόσφατες αναρτήσεις αντί για Κορυφαία αποτελέσματα. Μπορείτε πάντα να αλλάζετε καρτέλες αναζήτησης στο X όποτε θέλετε διαφορετική προβολή.

## Διατηρήστε τις συνήθεις αναρτήσεις Facebook ορατές

Το φιλτράρισμα διαφημίσεων στο Facebook ελέγχει πλέον απευθείας την ίδια την ετικέτα χορηγούμενου περιεχομένου. Οι συνηθισμένες αναρτήσεις που τυχαίνει να αναφέρουν λέξεις όπως «Ad» ή «広告» είναι πολύ λιγότερο πιθανό να αποκρυφτούν κατά λάθος.

## Πιο αξιόπιστη εισαγωγή cookie

Η εισαγωγή cookie του προγράμματος περιήγησης διατηρεί πλέον ονόματα που ξεκινούν με `__Host-` και `__Secure-`. Η διατήρηση αυτών των προθεμάτων βοηθά τους ιστότοπους να αναγνωρίζουν σωστά την εισαγόμενη περίοδο σύνδεσης.

Δείτε τις [σημειώσεις έκδοσης στο GitHub](https://github.com/nonbili/Nora/releases/tag/v0.9.5) για την πλήρη λίστα αλλαγών.
