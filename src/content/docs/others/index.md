In addition to NouTube, Nora, and Nori, nonbili builds several other open-source applications focusing on email, developer tooling, and language learning.

## Meron

A fast and secure email client designed for desktop and mobile, with chat-style conversations and kanban organization.

- **Website**: [https://meron.im/](https://meron.im/)
- **Repository**: [nonbili/meron](https://github.com/nonbili/meron)
- **Platforms**: Linux (Flatpak, Snap, AppImage), macOS, Windows, Android (Google Play, F-Droid), iOS (App Store)
- **Highlights**: Unified inbox, conversation chat view, kanban triage boards, media galleries, end-to-end local privacy.

See the dedicated [Meron](/others/meron/) page for details and store links.

## Tmiix

Tmux/SSH session and snippet manager.

- **Repository**: [nonbili/tmiix](https://github.com/nonbili/tmiix)
- **Releases**: [GitHub Releases](https://github.com/nonbili/tmiix/releases/latest)
- **Platforms**: macOS, Linux, Windows (built with Wails and Go)
- **Highlights**: Manage local and SSH remote tmux sessions and snippets in an intuitive graphical UI, direct clipboard image pasting into AI coding agents on remote servers, quick session switcher shortcuts.

See the dedicated [Tmiix](/others/tmiix/) page for details.

## Jamu

An Android and iOS app designed to help you learn and practice Japanese.

- **Repository**: [nonbili/Jamu](https://github.com/nonbili/Jamu)
- **Platforms**: Android (Google Play, F-Droid, GitHub Releases), iOS
- **Highlights**: Gojuon (五十音) kana charts, number practice, NHK Easy News reader with furigana, interactive quizzes, and cultural trivia.

See the dedicated [Jamu](/others/jamu/) page for details.
