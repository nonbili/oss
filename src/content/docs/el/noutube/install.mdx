## Μετά την Εγκατάσταση

- **Κινητό**: Ανοίξτε έναν σύνδεσμο YouTube ή YouTube Music στο NouTube εάν η συσκευή σας ρωτήσει ποια εφαρμογή να χρησιμοποιήσει. Σε iOS, συμμετάσχετε στην έκδοση beta μέσω του TestFlight.
- **Desktop**: Επιβεβαιώστε ότι η αναπαραγωγή λειτουργεί όπως περιμένετε πριν αλλάξετε προχωρημένες ρυθμίσεις.
- **Επέκταση**: Καρφιτσώστε την επέκταση NouTube στη γραμμή εργαλείων του προγράμματος περιήγησής σας, ή δείτε την [Επέκταση Προγράμματος Περιήγησης](/el/noutube/extension/) για λεπτομέρειες.
- Συνεχίστε με την [Επισκόπηση](/el/noutube/) για το πλαίσιο του προϊόντος, ή τα [Χαρακτηριστικά](/el/noutube/features/) για την πλήρη λίστα δυνατοτήτων.
