*2026年11月3日公開*

コピーした投稿リンクは余計なパラメータなしで共有しやすくあるべきですし、動画のダウンロードも **解析中** のまま止まるべきではありません。モバイル版 **Nora 0.9.4** は、リンクの共有、ファイルの保存、TikTok 動画の視聴に関する複数の不具合を解消しました。

## 余計なトークンなしで X リンクを共有

Nora では、投稿リンクをコピーまたは共有する際に、`s` や `t` などの X 共有パラメータを自動的に削除するようになりました。たとえば：

```text
Before: https://x.com/nonbili/status/1234567890?s=20&t=example
After:  https://x.com/nonbili/status/1234567890
```

投稿アドレスはそのまま維持され、余分な共有トークンのみが削除されます。このクリーンアップ処理は X および Twitter の投稿 URL にのみ適用されるため、無関係なページで同じ短いパラメータ名が使われていても影響はありません。

## 動画保存時の「解析中」での停止を解消

一部の動画ダウンロードで、ダウンロードが開始される前の **解析中**（Parsing）の段階で停止してしまう問題が発生していました。本リリースではこの不具合を修正し、該当するダウンロードが正常に続行できるようになりました。

また、Web ページが `blob:` URL を通じて生成したファイルでも、指定されたファイル名が保持されるようになりました。保存したファイルを後から見つけやすくなります。

## TikTok の全画面コントロールを復元

ページの HTML 本文の準備が整う前にスクリプトが実行された場合、Nora の TikTok 全画面コントロールが表示されないことがありました。読み込み順序に柔軟に対応するよう改善され、全画面ボタンが意図どおり表示されるようになりました。

すべての変更点については [GitHub のリリースノート](https://github.com/nonbili/Nora/releases/tag/v0.9.4) をご覧ください。
