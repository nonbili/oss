O NouTube tem uma compilação para computador para Linux, macOS e Windows.

## O que esperar

A versão para computador mantém a mesma ideia geral da aplicação móvel:

- YouTube e YouTube Music numa única aplicação
- Instaladores nativos para Linux, macOS e Windows
- Uma janela de computador para sessões mais longas de audição ou navegação

## Porquê utilizar no computador

Escolha a versão para computador se pretender:

- Empacotamento nativo para computador
- Reprodução em janela
- Fluxos de instalação específicos da plataforma para Linux, macOS ou Windows

## Quando preferir o computador

A versão para computador é a melhor opção quando pretende o NouTube como aplicação diária no posto de trabalho em vez de um leitor focado no telemóvel.
