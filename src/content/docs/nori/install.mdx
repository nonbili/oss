## After Install

- **Mobile**: Try sharing a link from your web browser to Nori using the system share menu to verify link handling.
- **Desktop**: On Linux AppImage, ensure GTK 3 and `webkit2gtk-4.1` are installed (`libwebkit2gtk-4.1-0` on Debian/Ubuntu, `webkit2gtk4.1` on Fedora, `webkit2gtk-4.1` on Arch).
- **Extension**: Pin the Nori extension to your browser toolbar for quick one-click bookmarking and searching.
- Continue with [Overview](/nori/) for product context, or [Features](/nori/features/) for the full capability list.
