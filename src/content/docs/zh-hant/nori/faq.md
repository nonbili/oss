## 如何從手機瀏覽器中將連結儲存至 Nori？

使用系統標準分享功能表：

1. 在瀏覽器（Chrome、Firefox、Safari、Brave 等）中，點選 **分享**。
2. 在應用程式列表中選擇 **Nori**。
3. 選擇儲存該連結的目標列表，或者在設定中開啟「快速儲存分享的連結」，無需確認即可直接儲存到指定列表。

## 可以直接在瀏覽器應用程式中開啟書籤而不是應用程式內分頁嗎？

可以。進入 **設定 → 一般** 並開啟 **在預設瀏覽器中開啟連結**。啟用後，點選任何書籤都會立即跳轉到手機的預設瀏覽器應用程式中開啟。

## 如何從桌面端瀏覽器匯入書籤？

將現有的書籤匯出為 HTML 檔案：

- **Chrome / Brave / Edge**：開啟書籤管理員（`Ctrl+Shift+O` 或 `Cmd+Option+B`）→ 點選 `⋮` 功能表 → 選擇 **匯出書籤**。
- **Firefox**：開啟收藏庫/管理書籤（`Ctrl+Shift+O` 或 `Cmd+Shift+O`）→ **匯入和備份** → **匯出書籤到 HTML…**。
- **Safari**：檔案 → **匯出書籤…**。

然後在 Nori 中進入 **設定 → 書籤 → 匯入書籤**，選擇該 `.html` 檔案，Nori 會將所有連結與資料夾匯入到對應的列表中。

## 可以備份和還原書籤嗎？

可以。在 **設定 → 書籤** 中：

- **匯出備份**：儲存包含所有列表、書籤、標籤與設定的完整 JSON 備份檔案。
- **還原備份**：從現有的 Nori 備份檔案進行還原。
- **匯出 HTML / 純文字**：產生相容瀏覽器的 HTML 檔案或易讀的純文字列表。

## 多裝置同步是如何運作的？

Nori Sync 將您的行動應用程式、桌面應用程式與瀏覽器擴充功能連接在一起：

- 書籤在每台裝置上都有完整的本地快取，完全支援離線使用。
- 連線網路時，所做的變更會在所有處於作用中的用戶端之間無縫同步。

## 瀏覽器擴充功能會追蹤我的瀏覽活動嗎？

不會。Nori 不會監控您的瀏覽紀錄，也不會讀取網頁內容。擴充功能僅在您主動開啟彈出視窗並點選收藏目前分頁時接收網址。
