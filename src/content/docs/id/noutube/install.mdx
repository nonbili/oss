## Setelah Instal

- **Seluler**: Buka tautan YouTube atau YouTube Music di NouTube jika perangkat Anda menanyakan aplikasi mana yang akan digunakan. Di iOS, bergabunglah ke beta melalui TestFlight.
- **Desktop**: Pastikan pemutaran berfungsi seperti yang Anda harapkan sebelum mengubah pengaturan lanjutan.
- **Ekstensi**: Sematkan ekstensi NouTube ke bilah alat browser Anda, atau lihat [Ekstensi Browser](/id/noutube/extension/) untuk detailnya.
- Lanjutkan ke [Ikhtisar](/id/noutube/) untuk konteks produk, atau [Fitur](/id/noutube/features/) untuk daftar kemampuan lengkap.
