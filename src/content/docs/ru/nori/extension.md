Nori включает локальное браузерное расширение для Mozilla Firefox и Google Chrome.

## Ключевые возможности

- **Повторяет мобильный интерфейс**: Всплывающее окно расширения предоставляет те же списки, панель поиска, историю, управление списками и настройки, что и мобильное приложение.
- **Добавление в один клик**: Мгновенно сохраняйте текущую вкладку в выбранный список с автоматическим получением заголовка.
- **Быстрый запуск**: Ищите и открывайте сохранённые ссылки в новых вкладках прямо с панели инструментов браузера.
- **Локальное хранилище**: Закладки сохраняются локально в хранилище расширения браузера с возможностью синхронизации через Nori Sync.
- **Конфиденциальность**: Расширение не отслеживает вашу историю просмотров и не читает содержимое страниц. Nori получает только те ссылки, которые вы сохраняете вручную.

## Установка расширения

Установите Nori напрямую из официальных каталогов расширений:

- [Firefox Add-ons](https://addons.mozilla.org/addon/nori/)
- [Chrome Web Store](https://chromewebstore.google.com/detail/nori/ojgmnocnegcbhlmfoackgoocnjbfejpg)

## Сборка из исходного кода

Расширение имеет открытый исходный код и построено с помощью [WXT](https://wxt.dev/) с использованием Manifest V3:

```bash
cd extension
bun install
bun run dev          # Режим разработки для Chrome
bun run dev:firefox  # Режим разработки для Firefox
bun run build:all    # Сборка готовых zip-архивов
```
