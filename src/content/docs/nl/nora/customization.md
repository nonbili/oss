Nora ondersteunt aangepaste CSS zodat je de ingesloten servicewebsites kunt vormgeven.

## Veelvoorkomende toepassingen

- Afleidende UI verbergen
- De informatiedichtheid verbeteren voor tijdlijn-georiënteerde indelingen
- Servicespecifieke interface-elementen verwijderen die je nooit gebruikt
- Meerkoloms desktopopstellingen overzichtelijker maken

## Houd wijzigingen onderhoudbaar

Omdat Nora afhankelijk is van de live websites van externe diensten, kan de bovenliggende HTML-structuur zonder waarschuwing veranderen.

Kies voor een behoudende aanpak:

- Geef de voorkeur aan kleine, gerichte regels
- Test opnieuw na herontwerpen van de dienst
- Vermijd brede overschrijvingen tenzij je de gevolgen ervan beheerst

## Combineer CSS met profielen

Als je aparte profielen gebruikt voor verschillende diensten of rollen, houd je CSS-aanpassingen dan afgestemd op die profielen zodat het gedrag voorspelbaar blijft.
