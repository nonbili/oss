## Як зберегти посилання в Nori з мобільного браузера?

Скористайтеся стандартним системним меню поширення:

1. У вашому браузері (Chrome, Firefox, Safari, Brave тощо) натисніть **Share** (Поділитися).
2. Виберіть **Nori** зі списку програм.
3. Виберіть цільовий список, у якому хочете зберегти посилання, або ввімкніть **Quick save shared links** у налаштуваннях, щоб зберігати безпосередньо у визначений список без запиту.

## Чи можна відкривати закладки безпосередньо у браузері, а не у внутрішній вкладці програми?

Так. Перейдіть у **Settings → General** і ввімкніть **Open links in default browser**. Коли цей параметр увімкнено, натискання будь-якої закладки одразу передаватиме URL-адресу до браузера за замовчуванням на вашому телефоні.

## Як імпортувати закладки з браузерів на комп'ютері?

Експортуйте наявні закладки у файл HTML:

- **Chrome / Brave / Edge**: відкрийте Диспетчер закладок (`Ctrl+Shift+O` або `Cmd+Option+B`) → натисніть меню `⋮` → виберіть **Export bookmarks**.
- **Firefox**: відкрийте Бібліотеку (`Ctrl+Shift+O` або `Cmd+Shift+O`) → **Import and Backup** → **Export Bookmarks to HTML…**.
- **Safari**: Файл → **Export Bookmarks…**.

Потім у Nori перейдіть до **Settings → Bookmarks → Import bookmarks**, виберіть файл `.html`, і Nori імпортує всі посилання та папки у відповідні списки.

## Чи можна створювати резервні копії закладок і відновлювати їх?

Так. У розділі **Settings → Bookmarks**:

- **Export backup**: зберігає повний файл резервної копії JSON, що містить усі списки, закладки, теги та налаштування.
- **Restore backup**: відновлює дані з наявного файлу резервної копії Nori.
- **Export HTML / Plain text**: створює сумісний із браузером HTML-файл або зручний для читання текстовий список.

## Як працює синхронізація між пристроями?

Nori Sync з'єднує ваші мобільні програми, програми для комп'ютерів і розширення для браузерів:

- Закладки залишаються локально в кеші кожного пристрою для повної роботи офлайн.
- За наявності підключення зміни безперешкодно синхронізуються між усіма активними клієнтами.

## Чи відстежує розширення браузера мою активність?

Ні. Nori не відстежує вашу історію переглядів і не читає вміст вебсторінок. Розширення отримує URL-адреси лише тоді, коли ви відкриваєте спливне вікно та натискаєте кнопку додавання поточної вкладки в закладки.
