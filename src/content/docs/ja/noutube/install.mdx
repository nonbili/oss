## インストール後

- **モバイル**: アプリ選択が表示されたら、YouTube または YouTube Music のリンクを NouTube で開いてください。iOS では TestFlight からベータ版に参加できます。
- **デスクトップ**: 高度な設定を変更する前に、再生が期待通りに動作することを確認してください。
- **拡張機能**: ブラウザのツールバーに NouTube 拡張機能をピン留めするか、詳細は [ブラウザ拡張機能](/ja/noutube/extension/) を参照してください。
- 概要については [Overview](/ja/noutube/)、すべての機能一覧は [Features](/ja/noutube/features/) を参照してください。
