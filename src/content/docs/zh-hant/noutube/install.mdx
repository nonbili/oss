## 安裝後

- **行動裝置**：如果您的裝置詢問應使用哪個應用程式，請在 NouTube 中開啟 YouTube 或 YouTube Music 連結。在 iOS 上，請透過 TestFlight 加入測試版。
- **桌面版**：在更改進階設定前，請確認播放效果符合您的預期。
- **擴充功能**：將 NouTube 擴充功能釘選到瀏覽器工具列，或參閱 [瀏覽器擴充功能](/zh-hant/noutube/extension/) 以取得詳細資訊。
- 請繼續閱讀 [概覽](/zh-hant/noutube/) 以獲取產品背景資訊，或閱讀 [功能](/zh-hant/noutube/features/) 以獲取完整功能清單。
