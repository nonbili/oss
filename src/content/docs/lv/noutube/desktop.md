NouTube ir datora versija operētājsistēmām Linux, macOS un Windows.

## Ko sagaidīt

Datora versija saglabā to pašu vispārējo ideju kā mobilā lietotne:

- YouTube un YouTube Music vienā lietotnē
- Natīvie instalētāji operētājsistēmām Linux, macOS un Windows
- Datora logs ilgākām klausīšanās vai pārlūkošanas sesijām

## Kāpēc izmantot datora versiju

Izvēlieties datora versiju, ja vēlaties:

- Natīvu datora pakotni
- Atskaņošanu logā
- Platformai specifiskas instalēšanas plūsmas operētājsistēmām Linux, macOS vai Windows

## Kad dot priekšroku datora versijai

Datora versija ir piemērotāka, ja vēlaties NouTube kā ikdienas darbstacijas lietotni, nevis tikai tālrunim paredzētu atskaņotāju.
