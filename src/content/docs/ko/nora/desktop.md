Nora는 Linux, macOS 및 Windows용 데스크톱 앱으로 제공됩니다.

## 데스크톱 버전의 추가 기능

데스크톱 버전은 여러 타임라인을 더 편하게 탐색할 수 있는 덱(Deck) 보기를 포함해 큰 화면에 맞춘 레이아웃을 제공합니다.

다음과 같은 경우에 데스크톱 버전이 특히 잘 맞습니다:

- 여러 피드를 동시에 모니터링할 때
- 계정이나 서비스별로 별도의 작업 공간을 열어 둘 때
- 간단한 모바일 도구보다 상시 사용하는 일상용 브라우저로 Nora를 쓰고 싶을 때

## 기대할 수 있는 기능

데스크톱 버전은 모바일과 동일한 전반적 제품 모델을 유지합니다:

- 하나의 앱 안에서 지원되는 소셜 사이트 열기
- 더 큰 화면에서 계정 분리 및 브라우징 도구 사용
- Linux, macOS 또는 Windows용 네이티브 패키지 설치
