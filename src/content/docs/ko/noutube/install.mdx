## 설치 후

- **모바일**: 기기에서 사용할 앱을 물으면 NouTube로 YouTube 또는 YouTube Music 링크를 열어 보세요. iOS에서는 TestFlight를 통해 베타에 참여할 수 있습니다.
- **데스크톱**: 고급 설정을 변경하기 전에 재생이 예상대로 작동하는지 먼저 확인하세요.
- **확장 프로그램**: NouTube 확장 프로그램을 브라우저 툴바에 고정하거나, 자세한 내용은 [브라우저 확장 프로그램](/ko/noutube/extension/)을 참고하세요.
- 제품 맥락은 [개요](/ko/noutube/)에서, 전체 기능 목록은 [기능](/ko/noutube/features/)에서 계속 확인하세요.
