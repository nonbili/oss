## Pēc instalēšanas

- **Mobilajā ierīcē**: mēģiniet kopīgot saiti no sava tīmekļa pārlūka uz Nori, izmantojot sistēmas kopīgošanas izvēlni, lai pārbaudītu saišu apstrādi.
- **Datorā**: operētājsistēmā Linux AppImage pārliecinieties, ka ir instalēti GTK 3 un `webkit2gtk-4.1` (`libwebkit2gtk-4.1-0` sistēmā Debian/Ubuntu, `webkit2gtk4.1` sistēmā Fedora, `webkit2gtk-4.1` sistēmā Arch).
- **Paplašinājumā**: piespraudiet Nori paplašinājumu pārlūka rīkjoslai ātrai grāmatzīmju pievienošanai un meklēšanai ar vienu klikšķi.
- Turpiniet ar [Pārskatu](/lv/nori/), lai uzzinātu produkta kontekstu, vai [Funkcijām](/lv/nori/features/), lai skatītu pilnu iespēju sarakstu.
