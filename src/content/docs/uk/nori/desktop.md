Nori надає окрему програму для комп'ютерів на Linux, macOS та Windows.

## Що додає версія для комп'ютерів

Версія для комп'ютерів переносить упорядковану панель запуску закладок Nori на ваш комп'ютер як швидкого помічника, зручного для роботи з клавіатури:

- **Окрема панель запуску**: тримайте свої посилання впорядкованими в незалежному вікні, не захаращуючи панелі вкладок браузера.
- **Локально орієнтована архітектура**: побудована на [Wails v3](https://v3.wails.io/) і Go, поєднуючи нативні вікна ОС із сучасними вебкомпонентами інтерфейсу.
- **Запуск у системному браузері**: натискання на посилання відкриває їх безпосередньо у вашому браузері за замовчуванням.
- **Інтеграція синхронізації**: підключіть обліковий запис Nori Sync, щоб легко ділитися закладками між комп'ютером, мобільним пристроєм і розширенням браузера.

## Пакунки для платформ

- **Linux**: розповсюджується у вигляді портативних пакунків AppImage та `.tar.gz` для `amd64`.
- **macOS**: універсальна підтримка для Apple Silicon (`arm64`) та Intel (`amd64`), розповсюджується у вигляді інсталяторів `.dmg` та архівів `.app.zip`.
- **Windows**: розповсюджується у вигляді інсталяторів (`.exe`) та портативних архівів `.zip`.

## Системні вимоги для Linux

Linux AppImage використовує системний рушій WebKit. Переконайтеся, що у вашій системі встановлено GTK 3 і `webkit2gtk-4.1`:

- **Debian / Ubuntu**:
  ```bash
  sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0 libfuse2
  ```
- **Fedora**:
  ```bash
  sudo dnf install webkit2gtk4.1 gtk3
  ```
- **Arch Linux**:
  ```bash
  sudo pacman -S webkit2gtk-4.1 gtk3
  ```
