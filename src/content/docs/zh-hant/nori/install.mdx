## 安裝後說明

- **行動裝置**：嘗試從 Web 瀏覽器透過系統分享功能表向 Nori 分享連結，以驗證連結接收功能。
- **桌面端**：在 Linux AppImage 上，請確保已安裝 GTK 3 和 `webkit2gtk-4.1`（Debian/Ubuntu 上為 `libwebkit2gtk-4.1-0`，Fedora 上為 `webkit2gtk4.1`，Arch 上為 `webkit2gtk-4.1`）。
- **擴充功能**：將 Nori 擴充功能釘選到瀏覽器工具列，以便一鍵新增書籤與快速搜尋。
- 繼續閱讀 [概覽](/zh-hant/nori/) 瞭解產品背景，或檢視 [功能](/zh-hant/nori/features/) 取得完整特性列表。
