Nora постачається як програма для комп'ютерів на Linux, macOS та Windows.

## Що додає версія для комп'ютерів

Версія для комп'ютерів додає макет, розроблений для великих екранів, включно з виглядом у вигляді колонок (deck view) для зручнішого перегляду кількох стрічок одночасно.

Це робить версію для комп'ютерів кращим вибором, коли ви:

- Стежите за кількома стрічками одночасно
- Тримаєте відкритими окремі робочі простори для різних облікових записів або сервісів
- Хочете використовувати Nora як постійний щоденний браузер, а не швидкий мобільний інструмент

## Чого очікувати

Версія для комп'ютерів зберігає ту саму загальну модель продукту, що й мобільна:

- Відкривайте підтримувані сайти соцмереж в одній програмі
- Використовуйте розділення облікових записів та інструменти перегляду на великому екрані
- Встановлюйте нативні пакунки для Linux, macOS або Windows
