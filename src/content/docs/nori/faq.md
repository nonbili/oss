## How do I save links into Nori from my mobile browser?

Use the standard system share menu:

1. In your browser (Chrome, Firefox, Safari, Brave, etc.), tap **Share**.
2. Select **Nori** from the list of apps.
3. Choose the target list where you want to store the link, or enable **Quick save shared links** in settings to save directly to a designated list without a prompt.

## Can I open bookmarks directly in my browser app instead of an in-app tab?

Yes. Go to **Settings → General** and turn on **Open links in default browser**. When enabled, tapping any bookmark will immediately hand off the URL to your phone's default browser app.

## How do I import my bookmarks from desktop browsers?

Export your existing bookmarks to an HTML file:

- **Chrome / Brave / Edge**: Open Bookmark Manager (`Ctrl+Shift+O` or `Cmd+Option+B`) → click the `⋮` menu → select **Export bookmarks**.
- **Firefox**: Open Library (`Ctrl+Shift+O` or `Cmd+Shift+O`) → **Import and Backup** → **Export Bookmarks to HTML…**.
- **Safari**: File → **Export Bookmarks…**.

Then in Nori, go to **Settings → Bookmarks → Import bookmarks**, select the `.html` file, and Nori will import all links and folders into corresponding lists.

## Can I backup and restore my bookmarks?

Yes. In **Settings → Bookmarks**:

- **Export backup**: Saves a complete JSON backup file containing all lists, bookmarks, tags, and settings.
- **Restore backup**: Restores from an existing Nori backup file.
- **Export HTML / Plain text**: Creates a browser-compatible HTML file or readable text list.

## How does multi-device synchronization work?

Nori Sync connects your mobile apps, desktop apps, and browser extensions:

- Bookmarks stay cached locally on each device for complete offline functionality.
- When connected, changes sync seamlessly across all active clients.

## Does the browser extension track my browsing activity?

No. Nori does not monitor your browsing history or read web page content. The extension only receives URLs when you open the popup and click to bookmark the current tab.
