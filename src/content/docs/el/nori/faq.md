## Πώς αποθηκεύω συνδέσμους στο Nori από το πρόγραμμα περιήγησης του κινητού μου;

Χρησιμοποιήστε το τυπικό μενού κοινοποίησης του συστήματος:

1. Στο πρόγραμμα περιήγησής σας (Chrome, Firefox, Safari, Brave κ.λπ.), πατήστε **Κοινοποίηση**.
2. Επιλέξτε **Nori** από τη λίστα εφαρμογών.
3. Επιλέξτε τη λίστα προορισμού όπου θέλετε να αποθηκεύσετε τον σύνδεσμο ή ενεργοποιήστε τη **Γρήγορη αποθήκευση κοινόχρηστων συνδέσμων** στις ρυθμίσεις για άμεση αποθήκευση σε προκαθορισμένη λίστα χωρίς επιβεβαίωση.

## Μπορώ να ανοίγω σελιδοδείκτες απευθείας στην εφαρμογή περιήγησης αντί για καρτέλα εντός της εφαρμογής;

Ναι. Μεταβείτε στις **Ρυθμίσεις → Γενικά** και ενεργοποιήστε την επιλογή **Άνοιγμα συνδέσμων στο προεπιλεγμένο πρόγραμμα περιήγησης**. Όταν είναι ενεργοποιημένη, το πάτημα οποιουδήποτε σελιδοδείκτη θα μεταβιβάζει αμέσως τη διεύθυνση URL στην προεπιλεγμένη εφαρμογή περιήγησης του τηλεφώνου σας.

## Πώς εισάγω τους σελιδοδείκτες μου από προγράμματα περιήγησης υπολογιστή;

Εξαγάγετε τους υπάρχοντες σελιδοδείκτες σας σε αρχείο HTML:

- **Chrome / Brave / Edge**: Ανοίξτε τη Διαχείριση σελιδοδεικτών (`Ctrl+Shift+O` ή `Cmd+Option+B`) → κάντε κλικ στο μενού `⋮` → επιλέξτε **Εξαγωγή σελιδοδεικτών**.
- **Firefox**: Ανοίξτε τη Βιβλιοθήκη (`Ctrl+Shift+O` ή `Cmd+Shift+O`) → **Εισαγωγή και αντίγραφα ασφαλείας** → **Εξαγωγή σελιδοδεικτών σε HTML…**.
- **Safari**: Αρχείο → **Εξαγωγή σελιδοδεικτών…**.

Στη συνέχεια, στο Nori, μεταβείτε στις **Ρυθμίσεις → Σελιδοδείκτες → Εισαγωγή σελιδοδεικτών**, επιλέξτε το αρχείο `.html` και το Nori θα εισαγάγει όλους τους συνδέσμους και τους φακέλους στις αντίστοιχες λίστες.

## Μπορώ να δημιουργήσω αντίγραφα ασφαλείας και να επαναφέρω τους σελιδοδείκτες μου;

Ναι. Στις **Ρυθμίσεις → Σελιδοδείκτες**:

- **Εξαγωγή αντιγράφου ασφαλείας**: Αποθηκεύει ένα πλήρες αρχείο αντιγράφου ασφαλείας JSON που περιέχει όλες τις λίστες, τους σελιδοδείκτες, τις ετικέτες και τις ρυθμίσεις.
- **Επαναφορά αντιγράφου ασφαλείας**: Επαναφέρει δεδομένα από ένα υπάρχον αρχείο αντιγράφου ασφαλείας Nori.
- **Εξαγωγή HTML / Απλού κειμένου**: Δημιουργεί ένα συμβατό αρχείο HTML για προγράμματα περιήγησης ή μια ευανάγνωστη λίστα κειμένου.

## Πώς λειτουργεί ο συγχρονισμός πολλαπλών συσκευών;

Το Nori Sync συνδέει τις εφαρμογές σας για κινητά, τις εφαρμογές desktop και τις επεκτάσεις περιήγησης:

- Οι σελιδοδείκτες παραμένουν αποθηκευμένοι τοπικά σε κάθε συσκευή για πλήρη λειτουργικότητα εκτός σύνδεσης.
- Όταν συνδέεστε, οι αλλαγές συγχρονίζονται απρόσκοπτα μεταξύ όλων των ενεργών συσκευών.

## Παρακολουθεί η επέκταση του προγράμματος περιήγησης τη δραστηριότητα περιήγησής μου;

Όχι. Το Nori δεν παρακολουθεί το ιστορικό περιήγησής σας ούτε διαβάζει το περιεχόμενο των ιστοσελίδων. Η επέκταση λαμβάνει διευθύνσεις URL μόνο όταν ανοίγετε το αναδυόμενο παράθυρο και κάνετε κλικ για να αποθηκεύσετε την τρέχουσα καρτέλα.
