## 列表分類

- **多列表**：將連結分類到清晰的列表中，如社群、工作、閱讀、新聞或 AI 工具。
- **列表管理**：根據工作流程需要隨時建立、重新命名、隱藏或刪除列表。
- **拖曳重排**：以直覺的拖曳操作將列表和書籤調整為您喜歡的順序。
- **批次移動與刪除**：選擇多個書籤以便在列表間移動，或批次清理過期項目。

## 啟動與瀏覽

- **轉移至系統預設瀏覽器**：直接在系統偏好的瀏覽器應用程式中開啟書籤。
- **應用程式內 Custom Tabs**：在 Android 和 iOS 上，可選用內建 Custom Tabs 或 Safari View Controller 視窗，無需離開應用程式即可快速檢視。
- **網站圖示解析**：自動擷取網站圖示（Favicon），亦可選擇顯示統一簡潔的 Nori 圖示。

## 系統分享功能表整合

- **接收系統分享**：從任何 Web 瀏覽器、通訊軟體或閱讀工具的分享功能表中直接將連結傳送至 Nori。
- **目標列表選擇**：在儲存時立即選擇想要歸類的目標列表。
- **快速儲存模式**：設定預設目標列表，無需彈出確認視窗即可直接儲存收到的連結。
- **自動抓取網頁標題**：新增連結時自動取得網頁標題。

## 檢視模式

- **精簡啟動器**：針對一鍵快速啟動和高資訊密度進行最佳化的精簡膠囊按鈕。
- **預覽卡片**：展示網站封面圖與描述摘要的圖文卡片。
- **版面配置密度**：支援單欄和雙欄網格版面配置，適配不同螢幕尺寸與閱讀偏好。

## 搜尋抽屜與歷史紀錄

- **快速搜尋**：即時依標題、網址或自訂標籤在所有書籤中進行篩選。
- **排序選項**：依最新、最舊、名稱遞增（A–Z）或遞減（Z–A）對書籤排序。
- **最近使用**：無需在各個列表中尋找，快速重新開啟最近啟動的連結。
- **最近新增**：一覽最新儲存的書籤。

## 匯入、匯出與備份

- **瀏覽器 HTML 匯入**：匯入從 Chrome、Firefox、Safari、Edge 或 Brave 匯出的標準 HTML 書籤檔案。
- **純文字匯出**：匯出易讀的標題和網址列表，方便記錄或筆記整理。
- **完整備份與還原**：儲存包含所有設定、列表與書籤的便攜式 JSON 備份檔案，隨時安全還原。

## 雲端同步

- **多裝置同步**：透過可選的 Nori Sync 在手機、平板、桌面端與瀏覽器擴充功能之間流暢保持列表和書籤同步。
- **本地優先架構**：所有書籤均在裝置本地快取，即使處於離線狀態也能正常使用完整功能。
