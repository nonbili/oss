## 安装后

- **移动端**：如果设备询问用哪个应用打开链接，请为 YouTube 或 YouTube Music 选择 NouTube。在 iOS 上，可通过 TestFlight 加入测试版。
- **桌面端**：在更改高级设置之前，请先确认播放效果是否符合预期。
- **扩展**：将 NouTube 扩展固定到浏览器工具栏，或查看 [浏览器扩展](/zh-hans/noutube/extension/) 了解详情。
- 继续阅读 [概览](/zh-hans/noutube/) 了解产品背景，或查看 [功能](/zh-hans/noutube/features/) 获取完整功能列表。
