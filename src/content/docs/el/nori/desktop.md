Το Nori παρέχει μια αποκλειστική εφαρμογή desktop για Linux, macOS και Windows.

## Τι Προσφέρει το Desktop

Η έκδοση desktop φέρνει τον οργανωμένο εκκινητή σελιδοδεικτών του Nori στον υπολογιστή σας ως ένα γρήγορο εργαλείο φιλικό προς το πληκτρολόγιο:

- **Αυτόνομος εκκινητής**: Κρατήστε τους συνδέσμους σας οργανωμένους σε ένα ανεξάρτητο παράθυρο χωρίς να γεμίζετε τις καρτέλες του προγράμματος περιήγησης.
- **Αρχιτεκτονική τοπικής προτεραιότητας**: Κατασκευασμένο με [Wails v3](https://v3.wails.io/) και Go, συνδυάζοντας την εγγενή διαχείριση παραθύρων του λειτουργικού συστήματος με σύγχρονα στοιχεία web UI.
- **Εκκίνηση στο πρόγραμμα περιήγησης του συστήματος**: Κάνοντας κλικ στους συνδέσμους, ανοίγουν απευθείας στο προεπιλεγμένο πρόγραμμα περιήγησης του υπολογιστή σας.
- **Ενσωμάτωση συγχρονισμού**: Συνδέστε τον λογαριασμό Nori Sync για απρόσκοπτη κοινή χρήση σελιδοδεικτών μεταξύ υπολογιστή, κινητού και επέκτασης περιήγησης.

## Πακέτα Πλατφόρμας

- **Linux**: Διανέμεται ως φορητά πακέτα AppImage και `.tar.gz` για αρχιτεκτονική `amd64`.
- **macOS**: Καθολική υποστήριξη για Apple Silicon (`arm64`) και Intel (`amd64`), διανέμεται ως προγράμματα εγκατάστασης `.dmg` και πακέτα `.app.zip`.
- **Windows**: Διανέμεται ως προγράμματα εγκατάστασης (`.exe`) και φορητά αρχεία `.zip`.

## Απαιτήσεις Συστήματος για Linux

Το Linux AppImage χρησιμοποιεί τη μηχανή WebKit του συστήματος. Βεβαιωθείτε ότι το σύστημά σας έχει εγκατεστημένα τα GTK 3 και `webkit2gtk-4.1`:

- **Debian / Ubuntu**:
  ```bash
  sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0 libfuse2
  ```
- **Fedora**:
  ```bash
  sudo dnf install webkit2gtk4.1 gtk3
  ```
- **Arch Linux**:
  ```bash
  sudo pacman -S webkit2gtk-4.1 gtk3
  ```
