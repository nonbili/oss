## 列表分类

- **多列表**：将链接归类到清晰的列表中，如社交、工作、阅读、新闻或 AI 工具。
- **列表管理**：根据工作流需要随时创建、重命名、隐藏或删除列表。
- **拖动重排**：以直观的拖拽操作将列表和书签调整为您喜欢的顺序。
- **批量移动与删除**：选择多个书签以便在列表间移动，或批量清理失效条目。

## 启动与浏览

- **移交系统默认浏览器**：直接在系统偏好的浏览器应用中打开书签。
- **应用内 Custom Tabs**：在 Android 和 iOS 上，可选用内置 Custom Tabs 或 Safari View Controller 窗口，无需离开应用即可快速查看。
- **网站图标解析**：自动获取网站图标（Favicon），也可选择显示统一简洁的 Nori 图标。

## 系统分享菜单集成

- **接收系统分享**：从任何 Web 浏览器、聊天软件或阅读工具的分享菜单中直接将链接发送到 Nori。
- **目标列表选择**：在保存时立即选择想要归类的目标列表。
- **快速保存模式**：设置默认目标列表，无需弹出确认窗口即可直接保存收到的链接。
- **自动抓取网页标题**：添加链接时自动获取网页标题。

## 查看模式

- **紧凑启动器**：针对一键快速启动和高信息密度进行了优化的紧凑胶囊按钮。
- **预览卡片**：展示网站封面图和描述摘要的图文卡片。
- **布局密度**：支持单列和双列网格布局，适配不同屏幕尺寸和浏览偏好。

## 搜索抽屉与历史记录

- **快速搜索**：实时按标题、网址或自定义标签在所有书签中进行筛选。
- **排序选项**：按最新、最早、名称正序（A–Z）或倒序（Z–A）对书签排序。
- **最近使用**：无需在各个列表中查找，快速重新打开最近启动的链接。
- **最近添加**：一览最新保存的书签。

## 导入、导出与备份

- **浏览器 HTML 导入**：导入从 Chrome、Firefox、Safari、Edge 或 Brave 导出的标准 HTML 书签文件。
- **纯文本导出**：导出可读的标题和网址列表，方便记录或笔记整理。
- **完整备份与恢复**：保存包含所有设置、列表和书签的便携式 JSON 备份文件，随时安全恢复。

## 云端同步

- **多设备同步**：通过可选的 Nori Sync 在手机、平板、桌面端和浏览器扩展之间无缝保持列表和书签同步。
- **本地优先架构**：所有书签均在设备本地缓存，即使处于离线状态也能正常使用全部功能。
